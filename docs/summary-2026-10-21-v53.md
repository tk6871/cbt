기능 커밋5873d1d1 완료. 실제 Push는 GitHub 터미널 인증 부재로 실패하여 GitHub Desktop의 Push origin이 필요하다. 배포 확인은 아직 하지 않았다.

- 회차별 문제의 종목 선택에 **설비보전기사** 추가. 기존 산업기사와 별개이다.
- 공개 시험 화면27회차(2006~2022),2,660문제. 2022년4과목80문제·이전5과목100문제를 원형 그대로 유지한다.
- 원문 정답·보기·등록 해설 연결. 이미지 없는 완전 동일 지문/보기/정답의99개 해설 재사용 포함 상세1,571개, 미등록1,089개. 전체 해설을 새로 작성하거나 사실 검증한 것은 아니다.
- 그림265개: 원본 보존, Mac arm64 Real-ESRGAN x4plus-anime tile256,4배 모델→2배 bicubic PNG. 다크/라이트/원본 설정 공통 사용.
- 전체/수록 최신4과목/구5과목 선택과 윤활관리500문제 보존. 2025년 개편 범위를 수록한 것으로 오해하지 않도록 안내한다.

## 검사

- 원문 DOM 대조2,660개, 원본/출력265쌍 크기·파일·SHA, 은행 고유ID/과목별 범위 검사 통과.
- typecheck·build·PWA611·패치노트 버전 일치·diff 검사 통과. 기존 큰 청크/Zod 경고 유지.
- 마지막 PWA 재검사에 걸린 미사용 생성 진입점 사본6개는 work/build-conflicts-2026-10-21-v611에 복구 가능하게 보관 후 재통과했다. 원본 문제 파일 삭제는 없다.
- 전체 구조 검사43,330문제·8,953이미지 참조: 구조 오류0/누락0. 전체 해설 품질 검사는 기존 공조 추가해설6건으로 실패하며 신규 종목 오류는0이다.
- 실제 화면: 종목 로딩·회차80/100문제·학습 정답 후 해설·도표/4개 이미지 보기·다크/라이트, 별도 탭 이어풀기 확인. iframe390/820/1440/3840 CSS 폭 검사. 실물기기 검사는 아니다.
- 검사 탭의 마지막 뒤로가기 이후 제어 응답 문제가 남아 CBT 제출·복귀 최종 확인은 미완료. 실제 회원 동기화·APK·배포 검사는 하지 않았다.

## 재현

- 원문 캐시를 보존한 Mac에서 tools/audit-maintenance-engineer.py로 원문·이미지 대조.
- tools/audit-maintenance-engineer-scope.ts를 기존 esbuild로 번들해 Node 실행.
- 캐시는 Git에서 제외한다. 다른 장치에서 재생성하려면 두 공개 목록과 시험 DOM을 다시 확보해야 한다. 원문 은행과 원본/출력 이미지, 해시 대장은 Git에 포함한다.
- HTTP403 발생 시 무리하게 우회하지 않고 정상 브라우저 열람 경로를 사용한다. 새 설치·압축·다른 종목 데이터 수정 없음.
