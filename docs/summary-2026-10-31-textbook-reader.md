# 교재 전용 풀이 화면 · 2026-10-31

## 반영 내용

- 회차별 문제의 ‘교재 페이지별’과 학교 시험 준비/신기술 학습관의 교재 버튼에서 사이트 메뉴 없는 전용 풀이 화면으로 진입한다. 기존 CBT·중간고사·필답 화면은 유지한다.
- 진입 시 목차·쪽 선택 팝업을 연다. 한솔/에너지 교재, 책 형태의 장·절 목차/검색, 쪽번호 이동, 연결 현황·안내를 탭으로 구분한다. 목차를 고르거나 쪽번호를 적용하면 팝업을 닫고 문제로 이동한다.
- 작성 중인 쪽번호는 팝업에서 적용해야 반영된다. 닫기/배경 클릭/Escape로 취소하며 포커스를 탐색 버튼에 돌린다. 숫자가 아닌 쪽·거꾸로 된 범위는 적용하지 않는다.
- 풀이 화면은 상단 목록/교재/목차·쪽 선택/계산기/설정, 현재 범위 정보, 책 형태 문제, 이전·다음 쪽으로 구성한다. 기존 공학용 계산기 진입도 보존했다. 긴 설명과 전체 대조 목록은 팝업 안으로 이동했다.
- PC/4K는 문제 읽기 폭을 제한하고 모바일은 한 열로 표시한다. 노치 여백과 하단 안전 여백을 고려한다. 이미지 파일 크기나 원본을 변경하지 않았다.
- 직접 답안 선택·설명·책 번호·좌우 열·기존 기록ID·다크/라이트·기존 범위 학습/CBT를 보존한다. 새로고침/브라우저 뒤로·앞으로 및 CBT에서 교재 복귀를 처리하고, 명시적인 목록 버튼은 과거 CBT 이력으로 돌아가지 않도록 한다.

## 범위와 남은 작업

- 이번 작업은 사용자 최신 요청의 UI 분리다. 개별 원문 검토 작업에서 남긴 수동 입력과 미검토 후보는 그대로 보존했다. 공개 문제 데이터는 여전히 기존1,687연결/125사본이며 준비 중인148사본을 새로 생성하거나 공개하지 않았다.
- 별도 버전업·커밋·Push·APK·배포는 하지 않았다. 공개 버전은5.6/캐시621이며 최종 통합 반영 때 배포 캐시와 버전을 함께 갱신해야 한다.
- 새 설치·다운로드·OCR·업스케일·이미지 경량화·원본 삭제·압축 없음. 기존 Mac Node/Chrome 도구만 사용했다.

## 검증

- 타입 검사와 production build 성공. 기존 큰 청크·Zod 주석 경고는 남는다. PWA621 검사 통과.
- 초기 PC 회귀에서 새로고침 후 명시적 목록이 과거 CBT 이력으로 돌아갈 수 있는 문제를 찾아 수정했다. PC의 기존 쪽별 회귀와 새 팝업/탐색 검사는 재통과했다.
- 모바일에서 숨긴 버튼 글자가 접근 가능한 이름에서도 사라지는 것을 확인해 목록/설정 버튼에 명시적인 이름을 추가했다. 수정 후 관련5spec×3화면 크기36검사를1.8분에 모두 통과했다. 렌더/이미지 로딩이 끝난 화면을 별도로 캡처했다.
- 추가 캡처 검사에서 휴대폰1회가 교재 진입 전 앱 초기 준비 화면에서 대기해 실패했다. 동일 코드의 휴대폰 단독 재실행은6.6초 통과했고, 최초 실패를 통과로 세지 않는다. PC·태블릿의 해당 추가 검사도 각각 통과했다. 최종 계산기 버튼 포함 전용 화면6검사는28.4초에 모두 통과했다. PC·휴대폰·태블릿의 최종 팝업/다크·라이트 풀이/4K 캡처를 육안 확인했다.
- 실제 기기·Safari·실계정 동기화·APK·실배포 검증과 전체 문항 개별 원문 검토 완료를 뜻하지 않는다.
