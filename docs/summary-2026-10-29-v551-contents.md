# v5.5.1 교재 목차와 느슨한 검색

## 사용 위치

회차별 문제 → 교재 페이지별 → 한솔 공조/에너지 선택 → 목차에서 골라 풀기.

- 장 → 절 → 본문·예제/핵심·실전예상문제로 펼치며 확인된 문제 수를 표시한다.
- 목차를 선택하면 현재 연결된 첫 문제 쪽과 범위를 채우고 일반 학습/CBT로 모아 풀 수 있다.
- 선택한 목차를 저장하고 ‘목차 다시 고르기’로 돌아간다.
- 핵심 모의고사도 목차에 포함한다. 확인하지 않은 쪽번호는 대조 중으로 남기며 임의로 만들지 않는다.

## 검색

- 예: `냉동 대용량 급속동결`, `급속동결 대용량 냉동`, `냉동대용량급속동결`, `압축긔`, `몰리엘선도`.
- 제목·본문·연관어 일부가 맞는 항목을 찾고 여러 단어가 맞은 순서로 정렬한다. 검색 결과에 일치한 단어와 현재 연결 문제 수를 표시한다.
- 에너지1,112개 고유 이미지 문항의 기존 OCR은 검색 보조로만 사용한다. 원문 이미지·정답·해설·선택 좌표는 바꾸지 않았다. 검색 자료는 에너지 선택 때 지연 로딩한다(빌드 약324KB/gzip98KB).
- 외부 AI/새 검색 서비스·패키지·모델 설치는 없다. 임의 문장의 의미를 완전히 이해하거나 모든 오타를 보정하는 검색은 아니다.

## 자료 기준과 미완료 범위

- 한솔1/3과목은 정상 교보 앱의 실제 목차를 읽었고2과목은 제공된 목차 사진/기존 확인 기록을 사용했다. 장 제목·시작 쪽·확인된 예상문제 쪽만 쓴다.
- 에너지 제공 스캔에는 앞쪽 목차가 없다. 본문 장 제목/스캔 범위와 회차 구성을 목차 형태로 정리했다는 점을 UI에 표시했다.
- 목차 탐색과 전체 문제 연결 완료는 다르다. 한솔367위치/에너지1,135위치의 기존 연결 범위는 그대로이며 미연결은 준비 중으로 표시한다. 구회차640개 새 은행/좌표31개 보강 등 앞서 남긴 작업도 유지한다.
- 교보 임시 가로 두 쪽 보기는OFF로 복원해 확인했고80% 읽기 위치로 돌아왔다. 캡처 허용/보안 설정은 바꾸지 않았다. 원본 파일과 사용자 실제 학습 기록을 유지한다.

## 실제 검증

-15개 관련 테스트: 장·절/쪽 경계, 부분·붙여쓰기·순서·가벼운 오타, 목차 클릭→범위 입력/문제, 검색 결과 없음, 에너지 보조OCR, PC/휴대폰/태블릿 크기, 기존 교재 페이지 선택·저장·CBT 답안 분리/이어풀기·해설 접기/다크라이트.
- 기존 교재 테스트 안의4K 폭/2열 검사, 대표 PC/휴대폰 화면 캡처 확인.
- 최종 통합 실행의4개 시간초과는 일시적인 자동 잠자기 방지 상태에서 같은 검사만 재실행해4/4통과했다. 붙여쓰기 검색 반례는 보정 후 단위검사를 재통과했다. 실패한 중간 실행을 최종 통과로 세지 않는다.
- 타입/production build/PWA619/changelog identity/소스 공백 검사 통과. 기존 큰 청크/Zod 경고 유지.
- 실물 기기/Safari/실계정 동기화/전체 메뉴 전수/실배포/APK 빌드/설치 검사는 하지 않았다. 새 이미지 변환·다운로드도 없다.
