# 공조 필답형 2023년 3회~2024년 2회 해설 스캔 대조 기록

- 자료: 사용자가 제공한 `문서.zip`의 스캔 21장
- 대상: 2023년 3회, 2024년 1회, 2024년 2회 각 12문항
- 원칙: 인쇄된 문제 번호를 그대로 덮어쓰지 않고 문제 문장·수치·그림으로 기존 문항을 대응했다.
- 결과: 36문항의 대응 관계를 확인했고, 문제에 필요한 도면·표·사진 25개만 분리했다. 해설·정답 문장과 필기 흔적은 이미지에 포함하지 않았다.

## 기존 번호에 대응한 인쇄 번호

| 기존 회차 | 기존 1~12번에 대응하는 스캔 인쇄 번호 |
| --- | --- |
| 2023년 3회 | 11, 1, 2, 5, 8, 6, 3, 4, 9, 12, 7, 10 |
| 2024년 1회 | 12, 7, 10, 1, 11, 2, 6, 3, 8, 9, 4, 5 |
| 2024년 2회 | 11, 12, 9, 1, 5, 2, 10, 6, 4, 7, 8, 3 |

## 확인된 차이

- 2023년 3회 기존 8번은 수액기 문제가 아니라 전자밸브(솔레노이드 밸브) 문제임을 원문에서 확인해 문제·정답·해설을 함께 교정했다.
- 2024년 1회 기존 9번은 실내 28℃형이었으나, 사용자 결정에 따라 스캔 원문의 20℃형과 답 15℃·0.004 kg/kg(DA)로 교체했다.
- 2024년 1회의 인쇄 5~8번은 사진이 중복되어 더 반듯하고 읽기 쉬운 쪽을 사용했다.

세부 좌표·해시·대응 관계는 `data/hvac-practical-2023-2024-book-scans.json`에 기록한다.
