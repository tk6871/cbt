# v5.8 — 교재 원문 우선 풀이 / 2026-11-03

## 이번 결정과 결과

사용자의 내일 수업 준비를 우선해 남은 기존 CBT 1:1 대조를 중단하고, 기존 정상 열람 캡처의 원문으로 먼저 볼 수 있게 전환했습니다. 새 업스케일링·OCR·모델·다운로드·설치·공유 압축은 실행하지 않았습니다. 이미 완료된 확대본은 유지합니다.

- 기존 미대조759위치에 대해397쪽의 원해상도 PNG를 새로 분리했습니다. 새 자산220,055,001바이트(약209.86MiB). 원문 글자·분수·그림을 OCR 텍스트로 바꾸거나 원본 해상도를 줄이지 않았습니다.
-632위치는 문제와 풀이의 화면 영역을 분리해 풀이·정답표를 접어 둡니다.127위치는 경계를 확정하지 못했으므로 풀이 포함 가능성을 표시하고 원문 쪽 전체 보기를 제공합니다. 이127곳을 문제/풀이 분리 완료로 세지 않습니다.
- 각 원문에서①~④ 선택·취소를 기록하며 이 기기의 localStorage에 저장합니다. 클라우드 동기화·시험 점수·기존 오답노트에 합산하지 않습니다. 정답 OCR을 자동채점 답으로 쓰지 않습니다.
- 책 쪽번호·좌우 열 순서와 목차의 ‘교재 원문’ 개수로 접근합니다. 다크/라이트·원본 이미지 설정, 한 쪽 전체 보기와 원문 이미지 확대 링크를 지원합니다. 정답표는 과도하게 축소하지 않고 원해상도 가로 스크롤로 읽습니다.
- 기존 채점 문제와 내부 충돌 보류12곳은 그대로입니다. 교재 원문 우선 수록은 전체 개별 대조나 정답 검증 완료가 아닙니다.

진입: 회차별 문제 → 교재 페이지별 → 공조 교재 교재 → 목차 또는 쪽번호. ‘교재 원문 · 자가확인’으로 표시합니다.
