# Q가 남는 위치와 비열 c 역산

- 요청: Q=G×c×Δt를 c에 관해 정리할 때 Q가 어디에 남는지 PDF에 쉽게 설명.
- 3쪽에 양쪽을 G×Δt로 나누는 분수식과 오른쪽만 약분되는 과정, c=Q/(G×Δt)로 등호 양쪽 자리를 바꾸는 과정을 추가했다. 분수를 뒤집는 것이 아님을 명시했다.
- c/1=c, 분모1은 빈칸이 아님, Q/1을 나누면 분모가1×G×Δt가 되는 이유도 설명했다.
- 29쪽 유지, 본문 크기 그대로. 기존36문제/최종 답/그림10회 삽입과 다른28쪽 텍스트는 동일하다. 문제은행과 웹 버전은 변경하지 않았다.
