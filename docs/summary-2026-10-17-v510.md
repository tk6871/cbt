# v5.10 작업 요약

사용자가 메뉴 문제가 ‘문제 풀이에서 뒤로 나온 뒤’ 발생했다고 알려줘 해당 경로를 추가 확인했습니다.

## 수정

PC용 사이드바 복귀 모션이 닫힌 모바일 메뉴에도 적용되고 있었습니다. 모바일에서는 이 모션을 제외하고, 닫힌 메뉴는 숨김·터치 제외 처리했습니다. 열린 메뉴·본문 Vue 전환·PC 모션과 기존 학습 기록은 유지합니다.

작은 오류 수정이며 끝자리9 다음 자리 올림 규칙으로5.9.9→5.10을 사용했습니다. 캐시는600입니다.

## 실제 확인

- 타입·빌드·PWA600·display 소스 감사·편집 diff 검사 통과
- 별도 로컬 주소390px에서 학습/시험 × 화면 뒤로/브라우저 뒤로4경로 확인
- 복귀 모션 진행 중에도 닫힌 메뉴는 숨김·터치 제외, 메뉴를 열면 글씨와 클릭 영역 표시
- 820px 학습 복귀·메뉴 열기,4K 학습 복귀·PC 사이드바 모션 유지 확인
- 사용자 원래 브라우저의 학습 세션 슬롯은 새 시험으로 덮지 않음

보고된 실기기의 ‘테두리만 남는 상태’ 자체는 재현하지 못했습니다. 이번에 확인한 복귀 모션 충돌과 동일 원인이라고 확정하지 않습니다. 실물 Safari/Android·장시간 반복·동기화·APK빌드·실배포는 검사하지 않았습니다. 원본 이미지/문항/해설/정답/좌표/의존성은 변경하지 않았으며 기존 빌드 경고는 남아 있습니다.

로컬 커밋 후 GitHub Desktop에서 Push origin을 누르면 됩니다.
