# v5.9.7 필답형 복원 비율 실전

## 사용하는 곳

공조냉동 → 시험 자료실 → 필답형 문제풀이 → **복원 비율 실전 시작**.

최근 복원9회차(2023년3회~2026년2회)108문항을 지문·답안 기준으로 직접 구분했다. 구성표 하나를 같은 확률로 선택하고 각 자리를 같은 유형의 다른 문제로 교체한다. 원 회차를 그대로 재현하거나 다음 시험 출제를 예측하는 기능은 아니다. 기존 일반 랜덤은 현재 선택 범위를 그대로 사용한다.

## 구성 근거

| 복원 회차 | 수치 계산 | 시퀀스·제어 | 공식만 쓰기 |
| --- | ---: | ---: | ---: |
| 2023년3회 | 2 | 2 | 0 |
| 2024년1회 | 2 | 1 | 0 |
| 2024년2회 | 2 | 2 | 1 |
| 2024년3회 | 1 | 2 | 1 |
| 2025년1회 | 2 | 2 | 0 |
| 2025년2회 | 2 | 2 | 0 |
| 2025년3회 | 2 | 2 | 0 |
| 2026년1회 | 2 | 1 | 0 |
| 2026년2회 | 2 | 3 | 0 |

나머지 자리는 해당 회차의 공조·선도/기기·계측/배관·시공/원리·서술 수를 유지한다. 시퀀스·제어는 회로 동작 외 접점·타임차트·제어 신호 흐름도 포함한다. 수치 계산과 공식만 쓰기는 별도다. 기존 ‘공기조화’ 분류에 있는2024년1회8번 혼합공기 계산도 계산으로 반영한다. 기존 원문 분류나 답안을 덮어쓰지는 않았다. 2023년2회는 교재 미대응 추가 복원이 섞여 있어 완성 회차 구성표에서 제외했다.

- 먼저 유형에 맞는 주제를 뽑고 그 주제의 복원 사례를 뽑는다. 반복 수록 횟수만으로 선택 확률이 올라가지 않게 했다.
- 한 시험에서는 검토한 동일 주제키와 동일 지문·답안의 중복을 허용하지 않는다. 문제를 덜 뽑거나 다른 유형으로 몰래 채우지 않고 구성 불가를 알린다. 전체 문제은행의 모든 의미 중복을 판정한 것은 아니다.
- 기초·사진·별도PDF·오래된 회차는 새 실전의 기본 출제 풀에서 제외한다. 기존 학습/일반 랜덤에서는 유지한다.

## 풀이·저장

- 12문제·90분. 문항당5점은 현재 은행의 학습용 배점이다. 공식 세부 채점표가 아니다.
- 제출 전 정답·해설·힌트·답안 골격·해설 영상·정답 도식 겹치기 접근을 숨긴다. 제출 후 답안과 비교해 자가채점한다. 자동 정답 판정은 아니다.
- 미채점 상태에서 약점을 확정하지 않고 채점 진행 상태를 표시한다. 전체 자가채점 뒤 분야별 분석을 보여준다.
- 실전별 별도ID로 입력·채점·S펜 저장을 분리한다. 원래 회차의 답안·학습 기록을 초기화하지 않는다. 이상 신고는 실전ID 대신 원문 문제에 연결한다.
- 동일 브라우저에서 새로고침하면 구성·작성 답안·남은 시간을 복구한다. 목록으로 나간 뒤 마지막 실전 이어풀기/답안·채점 보기가 가능하다. 목록에서도 제한 시간은 계속 흐른다. 새 시험은 마지막 실전 이어풀기 슬롯을 교체하므로 미완료일 때 확인한다. 실전 전체 이력 메뉴나 기기 간 실전 구성 동기화는 이번 범위가 아니다.

## 검증

- 출제 감사 도구로9개 구성표 각각300회, 총2700회 생성. 매번12문제/60점/유형 수 일치/검토 주제 중복 없음/원문 불변/별도ID와 원문 연결을 검사했다.108개 원문 모두 선택 가능한 것도 확인했다.
- 기존572문항 답안·그림 연결 검사, 타입 검사·production build·PWA597 검사를 실행했다. 기존 큰 청크와 라이브러리 주석 경고는 유지된다.
- IAB495폭에서 시작·제출 전 정답/힌트 숨김·12문제 보기·입력/시간/페이지 새로고침 복구·S펜 도구 로딩을 확인했다. 목록→새로고침→이어풀기, 시험번호1~12, 제출 후 설명·부분점수·미채점 안내, 원래 회차의 미채점/빈 답안 유지도 확인했다. 최종 시작 카드 스타일과 가로 넘침 없음도 확인했다.
- 실물S펜 필기·90분 실제 경과·모든 기기 화면/4K 전체 검사·APK빌드·배포·실계정 동기화는 하지 않았다.
- 원문 문제/정답/해설/이미지·의존성은 변경하지 않았다. 설치·다운로드·OCR·업스케일링·이미지 경량화 없음.

공식 시험 형식 참고: [큐넷 공조냉동기계산업기사 안내](https://www.q-net.or.kr/crf005.do?id=crf00503s02&jmCd=2590&jmInfoDivCcd=B0). 유형별 비율은 공식 기준이 아닌 보유 복원 자료의 학습용 분석이다.
