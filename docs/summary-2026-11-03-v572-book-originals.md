# v5.7.2 — 교재 미연결 원문 보강

## 이번 반영

- 교재와 기존 CBT를 연결하지 못했던 위치201곳을 원문으로 보강했다. 객관식175개, 본문 예제·검토용 원문26개다. 일반 기출·중간고사 은행에 섞지 않고 교재에서만 불러온다.
- 한솔 등록 위치는2,253개: 객관식 연결2,227개와 별도 원문26개다. **현재 등록 목록의 빈칸은0이지만, 전체 책의 모든 문제가 수록·검토됐다는 뜻은 아니다.**
- 문제·풀이402장을 분리했다. Mac arm64 Real-ESRGAN x4plus-anime, 타일256,4배 처리 후2배 bicubic, lossless WebP다. 여러 열·쪽으로 이어진 문제/풀이도 원문 영역을 이어 붙였다. 원본 캡처는 비공개 작업 폴더에 보존한다.
- 직접 확인한 수치·단위·보기·정답 차이를 교재용 텍스트40개에 반영했다. 준비돼 있던 이미지 정정156개도 생성해 전체 정정은321개(이미지281·텍스트40)다. 직접 교재 원문으로 대체한 준비용 PNG2개도 삭제하지 않았다.
- 계산 설명은 해당 교재의 실제 수치·보기·단위에 맞췄다. Wh로 계산할 때3600으로 또 나누지 않는 이유, 동결점까지 내려가지 않으면 잠열을 쓰지 않는 이유, 혼합/BF·현열·엔탈피 조건을 구분한다. 원래 해설은 추가로 보존한다.
- 원문 자체의 지문/보기/정답표/풀이 충돌12곳은 표시하고 객관식 출제를 막는다. 예를 들어3-133쪽20번은 풀이가①버큠 브레이커를 설명하지만 정답표는②다. 이 불일치를 임의로 정상 문제로 만들지 않았다.
- 예제만 있는 쪽에서도 인쇄 쪽번호·이전/다음 이동을 유지한다. 한 쪽짜리 예제의 풀이 쪽번호와 이미지 대체문구도 바로잡았다.
- 새 원문의 보기 영역은 여러 줄을 하나로 묶은 직접 확인 좌표다. 마우스 영역과 선택 강조를 같은 영역으로 사용해 선택 뒤 자동 픽셀 추정으로 다시 줄어들지 않도록 했다.

## 검증과 보존

- 기존 일반 공조·한솔 공조·에너지 주요 원문 은행6개에 변경 없음. 기존 공개 풀이ID 보존을 검사한다.
- 원문 영역·원본 화면SHA·생성 이미지SHA·2배 크기·모델/타일·보기 겹침을 자동 검사한다. 직접 추가한 원문은 시각 proof로 검토했고 잘린 첫줄/마지막줄3곳을 수정했다.
- 타입 검사·production build·PWA624·패치노트 버전 일치·단위 검사10개 통과.
- 201입력·40텍스트 상태의 교재 관련 Chrome PC 검사14개 통과. 새 객관식175개×4보기의 선택/취소·좌표와 분수 그림·원문 해설 분리·다크/라이트·저장 복원·예제 쪽 이동을 포함한다.
- 이후 선택 영역 단일화 후 native3검사를 재통과했다.175문제×4보기 모두 마우스 영역과 선택 강조 박스의 위치·크기가 일치하고, 선택/취소가 동작한다.
- 실물기기·Safari·회원 동기화·배포본은 이번에 검사하지 않았다. 작은 업데이트이므로 전체 모바일/태블릿 화면 검사를 반복하지 않았다.
- Android 빌드 설정만624/5.7.2로 맞췄고 APK는 생성·설치하지 않았다. 온라인 화면은 웹 배포를 따른다.

## 남은 범위 — 완료로 처리하지 않음

- 전체 개별 대조 큐에는 **미검토 후보875개**가 남는다(정답 관련48·수치445·그림81·문장133·검색168). 후보 수는 실제 문제 총수나 확정 미수록 수가 아니다.
- 별도의 검토 보류12개와 미검토875개를 합친 비교판 항목은887개다. 빈칸0과 미검토0은 다른 수치다.
- 다음 작업은 이 후보들을 정상 원문과 계속 개별 대조하는 것이다. 숫자만 다른 경우도 지문·보기·정답표를 직접 확인한 뒤에만 텍스트 사본으로 반영한다.

## 재생성 주의

- `tools/hansol-book-native-review.json`이 직접 확인한 원문/보기 경계의 입력이다. `prepare-hansol-book-native.py`→기존 업스케일러→`build-hansol-book-native.mjs` 순서다. 일반 생성기를 실행한 뒤에도 native 생성/검사를 함께 실행한다.
- Mac 기존 Python/Pillow/numpy·arm64 Real-ESRGAN과 Git제외 원본 작업 폴더가 필요하다. 새 설치·다운로드·권한/보안 설정 변경·압축·원본 삭제·문제 이미지 경량화는 하지 않았다.
- 캡처/OCR/검토판/proof는Git제외다. 공개 결과에는 개별 문제·분리 풀이·검토 메타데이터만 반영한다.
