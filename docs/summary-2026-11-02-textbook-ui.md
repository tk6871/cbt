# 교재 선택·풀이 UI 재구성 · v5.7

## 바뀐 화면

- 회차별 문제 → 교재 페이지별을 누르면 메뉴 안에서 책·목차·단원·문제 쪽을 고른다. 기존 ‘교재 열기’ 안내만 있던 빈 화면을 없앴다.
- 목차를 고르는 것만으로는 독립 화면으로 이동하지 않는다. 단원 펼치기·쪽 선택을 실행했을 때 실제 문제 풀이만 독립 화면으로 열린다.
- 풀이 지면은 카드 대신 연속된 책 페이지다. 확인된 좌우 열·교재 번호·단원 제목·인쇄 쪽번호를 사용한다. 한 열만 등록된 쪽의 빈 반쪽, 반복 번호·과목 배지·큰 안내를 줄였다.
- 인쇄 쪽번호를 누르면 이동 팝업이 열린다. 기존 목차 검색·쪽 넘김·설정·계산기·이미지 확대·답안 선택·정답 해설·북마크·이상 신고·범위 학습/CBT를 유지한다.
- 목록 복귀·뒤로/앞으로·새로고침·CBT 후 같은 교재 쪽 복귀를 유지한다. 기존 답안·선택 쪽 저장 키와 독립 풀이ID를 변경하지 않았다.
- 다크·라이트·4K 최대 읽기 폭·휴대폰/태블릿 한 열 배치를 반영했다. 이미지 경량화·교체·새 다운로드/설치 없음.
