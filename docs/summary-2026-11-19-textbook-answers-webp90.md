# 교재 정답·풀이와 이미지 개선 — v6.2.56 / 웹 v698

- **사용 방법:** 회차별 문제 → 교재 페이지별 → 교재·쪽 선택. 직접 수록 문항에서 인쇄 보기나 번호 버튼을 누르면 정답 번호와 풀이가 열린다. 일반 CBT 점수에 합산하지 않으며 기존 선택 기록은 보존한다.
- **정답·배치:** 직접 수록 743문항의 정답을 인쇄 정답표에 연결했다. 잘못 읽은 번호 11개를 교정하고 중복 조각 6개는 원본을 삭제하지 않고 숨겼다. 현재 자료에서 36번은 5-33쪽(①), 5-35쪽 46번은 순환펌프 양정(③)이다.
- **이미지:** 원본 해시와 좌표를 유지해 새로 383쪽을 2배 확대 후 WebP 품질 90으로 압축했다. 기존 무필기 개선본 14쪽을 합쳐 397쪽이다. 별도 풀이 조각 2장도 같은 방식으로 연결했다. 에너지 3,358장과 공조 개별 문제·해설 500장의 기존 변환 기록·해시·출력 크기를 확인해 재압축하지 않았다.
- **병합 후 검증:** 원격 main의 공조·산업안전 기출 검토 커밋 `67365b0f`까지 포함했다. 한솔 3,085문항·에너지 1,709문항의 정답·해설·문항 및 이미지 연결 누락 0건. 타입 검사, 웹 빌드, PWA 캐시 v698, diff 검사 및 데스크톱 Chrome 회귀 7건 통과. 검사 항목에는 정답 표시, 보기 선택 기록, 다크·라이트 및 확대 이미지 요청 실패 시 원본 복귀가 포함된다.
- **범위:** 연결 검사가 모든 해설의 학술적 재검산을 의미하지는 않는다. 빌드의 기존 큰 청크 경고는 남아 있다. 이번 검증은 실기기·APK 설치 검사가 아니다.
