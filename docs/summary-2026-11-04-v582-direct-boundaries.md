## 실제 반영 내용

이전의 ‘미분리127곳’은 모두 실제 문제가 아니었다. 본문 제목/표를 문제로 오인한6곳과, 숫자 일부를 번호로 읽어 이미 연결된 문제를 중복 표시한4곳을 구분했다. 실제117문제는 문제·조건표·네 보기와 인쇄 풀이를 직접 읽고 영역을 나눴다. 현재 자가확인 원문은749위치이며 원래759위치의 보관 자료는 수정하거나 삭제하지 않았다.

- 문제 안 강우량표·온도표·NAND 진리표를 풀이로 숨기지 않는다.
- 다음 열/쪽 풀이와 참조하는 공통 그림을 함께 연결한다.
- 5.5kW·6.8·17.5 등의 숫자를 번호로 오인한 경우 첫줄과 인쇄 번호를 복구한다. 기존 저장ID는 그대로다.
- 풀이 이미지는 펼칠 때만 표시한다. 정답표·한 쪽 전체 보기는 명시적으로 누른 경우에만 보인다.
- 분리 보정은 원래 질문 영역이 일치할 때만 적용한다. 개선본 연결 실패 시 원해상도·전체 쪽·링크·상태 안내가 함께 대체된다.
- 기존397쪽에 없는1-107/1-113 풀이만 원해상도PNG2영역,76,446바이트 추가했다. 새 업스케일·OCR·재캡처·설치·다운로드·색삭제·원본삭제·압축은 하지 않았다.

개별 확정은 `tools/hansol-direct-boundary-review.json`, 화면 연결은 `data/hansol-book-direct-boundaries.json`, 재생성/원본픽셀 검사는 `tools/publish-hansol-direct-boundaries.py`에 있다. 자동 제안이나 색상 검출만으로 검수 완료로 세지 않는다. 기존 일반은행6개·교재은행1개와 원본/필기숨김 manifest 등11개 입력의 시작 전SHA를 보존 검사했다.

## 마감·남은 범위

코드·데이터·빌드·문서는 로컬 반영 완료. GitHub 플러그인의 저장소 정보에는 push 권한이 보이지만 실제 blob 쓰기가 다시403으로 거부됐다. 새 blob/tree/commit/ref 갱신은 성공하지 않았고 터미널 Git·GitHub Desktop·공유 방식으로 우회하지 않았다. 따라서 커밋·Push·배포 완료가 아니다. 위 Summary/Description을 사용자가 커밋할 때 사용한다.

이번 완료는127곳의 화면 경계 검수다. 원문759곳 전체의 기존 CBT 개별 대조·학술 정답 검증·채점 문제화와 별도 보류12곳은 남는다. 전자책 뷰어 앱/보안 설정/원래 읽던 위치는 이번 작업에서 조작하지 않았다. 다음 장치에서는 미커밋 변경을 보존하고 원격과 동기화한 뒤 작업한다. 재생성에는 기존 Python/Pillow와 비공개 캡처/page-map이 필요하며 공개 리뷰/manifest 및 앱 검사는 기존 Node/Chrome으로 실행한다.
