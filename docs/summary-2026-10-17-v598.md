# v5.9.8 필답형 화면 정리

- S펜 답안지·도구·캔버스 로딩 제거. 기존 필기 데이터와 원본 소스는 삭제하지 않았다.
- 문제와 그림 아래 ‘정답·풀이 보기’로 핵심 답안과 설명을 펼친다. 직접 입력·힌트·세부 채점은 필요할 때만 연다. 복원 비율 실전의 제출 전 정답 숨김은 유지한다.
- 표시 개수:1·2·4·6·8·10·12개 또는 이어보기. 같은 브라우저에서 개수와 학습 방식을 기억한다.
- 넓은 화면은 여러 문제 두 열, 한 문제는 최대920px. 긴 그림은 최대620px 높이 안에서 비율을 유지하며 원본 크게보기도 가능하다. 이미지 파일을 축소 변환한 작업은 아니다.

## 실제 검사

타입·빌드·PWA598, 표시 설정 복원 도구, 기존2700회 출제 감사와572문항/그림 연결 검사를 실행했다. 사용하지 않는 필기 청크가 SW 사전 캐시에 남지 않는지도 검사했다.

IAB495폭에서 각 표시 개수의 카드 수, S펜 캔버스0, 입력칸 접힘, 문제 아래 풀이·설명 기본펼침을 확인했다.6개·암기 모드는 새로고침 후 같은 회차에 다시 들어가도 복원됐다. 복원 비율 실전은 제출 전 풀이/힌트0, 제출 후 풀이 공개가 유지됐다.

3840×2160 화면 에뮬레이션으로 두 열 배치·한 문제920px·풀이 위치·가로 넘침 없음·그림 비율 유지를 확인했다. 임시 화면 크기는 원래대로 복구했다. 전체 기기 검사나 실제4K 모니터/성능 검사, APK빌드·배포는 하지 않았다.

문제·정답·해설·이미지·좌표와 기존 작성 답안/점수는 변경하지 않았다. 새 도구 설치나 다운로드도 없다. 자세한 실제 결과와 한계는 WORK_STATE에 기록했다.
