# v5.2 통합 작업 요약 — 2026-10-20

## 변경

- 계산 목록: 40개 이후 문제도 페이지 이동으로 접근, 잘못된 빈 목록 안내 수정, 필터 초기화.
- 이미지 문제의 검색/오답/계산 목록: OCR 글자 대신 접는 원문 미리보기. 원본 파일·픽셀·문제/정답은 변경하지 않음.
- 필답 계산: 공식/문제 목록 바로가기와 빈 필터 복귀. 기존 계산자료와 PDF 유지.
- 합격 엔진: 기록이 없으면 기초/첫 진단으로 안내.
- 신기술 학습관: 긴 과거 안내를 접어서 현재 기능과 구분.
- 내부 운영: 로그인 상태 갱신, 오래된 응답 차단, 신고 저장 확인·실패 복구·입력 보존·순서 제어. 실제 데이터/회원 권한 변경 없음.
