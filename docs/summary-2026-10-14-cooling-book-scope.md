- 사용자가 최종 확정한 범위는 **2과목 냉동냉장 설비 본문에 실린 문제 전체**다. 단원별 핵심/실전/예제 문제를 포함하고 책 맨 뒤 회차별 기출 부록은 제외한다. 안전관리 문제는 별도로 유지한다. 아래 최초 핵심 우선 기록보다 이 확정이 우선한다.

- 냉동장치 구조 일부 핵심83개 위치·회차·검색 단서를 추가 보존했다. 누적180개에서175개 검색 후보,147개 짧은 문구 포함 후보가 나왔다. 이 수는 전체 본문 문제 수나 동일 문제 확정 수가 아니다. 실전/예제와 나머지 장 대조는 남았다.
- 비공개 추가 파일은 `work/cooling-book-scope/structure-questions-progress.json`. 도구가 이전97개와 합산하며 published src/data/이미지/배포·앱 버전은 변경하지 않는다. Node 구문·180개 위치 고유성·비공개Git제외 확인. 빌드/화면/APK검사 미실행.

## 최초 조사

- 사용자는 교보 웹/앱에서 연 한솔아카데미 『2026 공조냉동기계산업기사 필기 5주완성』의 2과목 문제를 기존 중간고사에 연결해 범위를 줄이도록 요청했다.
- 기존 교수님 안내는 핵심예상문제였다. 핵심/실전/예제 포함 여부 질문은 아직 응답 전이며, 핵심예상문제를 우선 탐색했다.
- 웹 목차에서 2과목 전체 PDF259~546, 냉동이론267, 구조369, 응용/안전관리475, 부하527, 설치533, 냉방설비운영539를 확인했다. 실제 화면에서 PDF276~357의41개 펼침 화면을 읽었다. 전체 교재 대조 완료가 아니다.
- 냉동이론 핵심예상문제의 인쇄쪽2-18~21/32~36/44~47/60~63/74~75/84~86에서97개 문제의 위치·출제연도/회차·검색 단서를 비공개 작업 폴더에 기록했다. 문서에 기재된 회차는 출제 근거이고 책 문제 번호와 기출 문제 번호는 서로 다르다.
- 기존 공조/한솔 은행에서96개에 검색 후보가 있었고80개는 짧은 검색 문구 포함 후보가 있었다. 숫자/보기/도표/정답 동일성 검증 전이므로97개 확정 연결 또는96개 동일 문제라고 보고하지 않는다. 인쇄2-33의11번은 현재 단서로 후보를 못 찾았다.
- 제2~6장 실제 문제 대조와 수식/그림·보기 대조는 남았다. 안전관리를 별도 모으는 기존 원칙도 유지한다.

## 중단 사유

교보 웹 뷰어가 `정상적인 접근이 아니므로 이용을 중단합니다`라는 비정상사용도서 화면을 표시했다. 접근 제한을 우회하거나 계속 재접속하지 않았다. 그 전에 웹 탭 자동 닫힘과 제어 연결 끊김도 있었다. 중복 뷰어 영향을 확인하기 위해 앱 종료를 시도하고 웹으로 읽었지만 차단의 정확한 원인은 확정하지 못했다.

남은 문제는 사용자가 제공하는 사진/스캔본 또는 서비스에서 허용하는 내보내기 자료를 받아 대조한다. 전자책 원본·본문 전체·화면 캡처·로그인 URL/티켓을 공개 저장소에 추가하지 않았다.
