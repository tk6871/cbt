# v5.3.5 - 실제 계산 중 절대온도 대입 구분

## 반영한 의미

- 온도 자체T를 넣는 카르노 온도비·이상기체·이상적인 압축 온도비는 절대온도K로 변환한다.
- 비열의K만으로 판단하지 않는다. Q=GcΔt의 온도차에273.15를 더하지 않는다.
- 36개 계산식과 등록572문제 텍스트의 관련 후보를 확인했지만, 현재36계산에 필수 절대온도 수치 기출을 찾은 것은 아니다. 원문 이미지 새OCR·전수 대조는 하지 않았다.
- 카르노 냉동COP9.58 예시는 등록 기출과 구분한 설명용 예시다. 웹SI와 두 PDF에 가로 분수로 제공.
- 온도차13/단순혼합3/계수단위1에 해설 추가. 기존 혼합3문제는 K변환·가중평균·섭씨복귀를 선택해서 본다. 원래 섭씨 풀이는 유지.
- 지문·정답·기존 주 수식·반올림·원본그림·학습기록 유지. 새 기출·출제비율 추가 아님.
