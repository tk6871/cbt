# v6.0.1 OCR 원문 대조·교재 채점·모바일 보강

## Summary

`v6.0.1: OCR 수치·단위 검수 및 교재 채점·속도 개선`

## Description

- 수치·단위·부정 표현이 포함된 우선 표본 24개를 실제 이미지와 비교했습니다. 22개를 확인된 텍스트로 옮기고, 2개는 수기 판단으로 원문을 유지합니다. 유사 단위 오독 신호가 있는 임시 후보 18개는 추가로 이미지로 돌렸습니다. 확인 35개·임시 1,921개이며 전수 육안 검수는 아닙니다.
- 8쪽의 인쇄 정답표와 해당 객관식 네 보기를 대조해 원문 15문제를 교재 화면에서 채점합니다. 쪽 이미지의 식별값과 문항 번호·영역이 일치할 때만 동작합니다. 선택 저장 키와 일반 CBT 점수·오답 기록은 건드리지 않았습니다.
- 교재에 들어갈 때 목차 정렬을 재사용하고, 검색 텍스트와 숨겨진 목차 창은 필요할 때 준비합니다. 교재 은행은 재사용하고, 기존 이미지와 수식 엔진은 바꾸지 않았습니다.
- 같은 Mac Chrome에서 iPhone 14 Pro 화면, 4배 CPU 제한, 75ms 지연·10Mbps 다운로드를 모사한 3회 중앙값입니다. 교재 목록 준비 10.77→6.65초, 첫 쪽 이미지 표시 2.08→0.86초, 다음 교재 쪽 0.29→0.25초, 수식 도구 3.40→3.36초입니다. 일반 CBT 다음 묶음은 변경 후 1.70초이며 이전 값과 비교할 수 없습니다. 실기기나 공용 사이트의 실측은 아닙니다.
- Mac의 서명 빌드를 동기화 폴더 밖에서 처리해 중복 파일로 인한 빌드 실패를 해소했습니다. v6.0.1 설치 파일의 서명·패키지·버전과 기존 릴리스 인증서 일치를 검증했습니다. GitHub 업로드·실기기 설치는 하지 않았습니다.
