# 계산 PDF 재검토와 간소화

- 상세본34→29쪽,36문제·기존 최종값·그림10회 삽입 유지. 본문11pt 유지.
- 식 기초4→2쪽. 반복되는 문제 숫자 목록/원리 설명을 줄이고24개 분수 풀이에 간결한 설명을 작성했다. 공식 변형은 공통 원리와 연결해 묶고 답은 초록색으로 표시한다.
- 진공압300 mmHg 예제의 중간값61.327…를61.328289…로 바로잡았다. 최종61.33 kPa 유지. ‘셋째 자리에서 반올림’과 ‘셋째 자리까지’ 예시 추가.
- 한글 공식 요약은1쪽 유지. 질량당 잠열, 열량/열부하, kW와초당 유량, 시간당 환산, 회전수 배수 설명 보강.
- 문제은행·정답·웹 UI/버전5.3·캐시611·APK는 변경하지 않았다. BF 그림의 PDF상 배치 높이만125pt로 조정했으며 원본 이미지는 동일하다.

## 실제 확인

- 독립 산술41건 통과. 소수처리 예외를 포함한다.
- 생성기에서36개 지문과 기존 최종값 포함 확인, 문제 유형 누락/중복 없음, 우선13개 유지.
- 기존 PDF의 이미지 픽셀 해시10건과 모두 일치.
- 29쪽 상세본+1쪽 요약 전체 글자 페이지 경계 이탈0, 상세본 책갈피7개 유지.
- 최종 전체 페이지를 PNG로 렌더한 모음 확인, 기초/일부 문제/BF/요약 확대 확인. 기존 등록된 최종값 비교이지 모든 복원 원문을 재수집해 사실 검증한 것은 아니다.
- 웹 빌드·기기 화면·APK·실물 인쇄는 실행하지 않았다. 실험 중 페이지 수 증가와 요약2쪽 생성은 수정했으며 최종 결과로 기록하지 않는다.

## 재현

기존 bundled Python으로 tools/build-practical-calculation-study.py와 tools/build-practical-formula-quick-sheet.py를 실행한다. 상세본은 기존 tmp/pdfs/practical-calculation-study.json 자료를 사용한다. PDF 전용 간결한 설명은 tools/practical_pdf_solutions.py에 있다. 새 도구 설치 없음.

이번 작업은Mac에서 진행했다. 시작 시main은1커밋 앞서 있었다. GitHub Desktop에서Push origin 후 다른 장치에서Pull한다.
