# 에너지 중간고사: 교재 PDF와 기존 CBT 대조

## 이번 범위

사용자 제공 교재 뒤 기출 부분에는 2018~2020년8회차640문항과 2021~2025년13회차1,040문항이 있다. 앞 부분의 회차는 기존 에너지 CBT에 포함되어 있고, 후기13회차는 기존 목록에 없다. 후기 자료는 교재의 CBT 복원문제이며 실제 시험지 전체와 동일하다고 보장하지 않는다.

사용자가 요청한 중간고사20주제 관련 후기 문제만 먼저 검토했다. OCR은 페이지와 후보를 찾는 데 사용했으며 문제/보기 표시에는 OCR 전사문을 넣지 않았다. 모든1,040문항의 내용·정답을 검증한 것은 아니다.

## 원문 검토와 반영 수량

- 후보84개 모두 문제·보기·정답표를 직접 대조하고 온전한 크롭을 확인했다. 최초70개와 경계 보완14개를 반영했고 보류0개다.
- 완전히 같은 질문과 보기/정답인 후기 반복을 합쳐 PDF 원문73문제로 연결했다. 기존136문제 중30문제는 학교 문항ID와 답안을 그대로 유지하면서 PDF를 연결했고, 별도43문제를 추가하여 전체179문제가 됐다.
- 84개 출처의 대응·처리 내역은 `data/energy-midterm-selection.json`의 `pdfSelections`에 있으며, 합쳐진 문항에도 `midtermPdfSources`로 모든 출처를 남겼다.
- 기존 일반 에너지33회차2640문제는 수정하지 않았다. 일반 기출 기록과 학교 연습 기록은 분리한다.
- 교재 대응 확인은 기존27개 중9개와 이번 PDF73개가 겹쳐 고유91문제다. 출제 메모 직접 대응114개/추가 예상65개와는 서로 다른 분류 축이다.

## 반복 확인 기준

단어 유사도는 후보 탐색에만 사용했다. 저장 CBT 질문·보기와 PDF 원문·정답표를 수동 대조했다. 같은 개념만 묻는 문제를 완전 중복으로 합치지 않으며, 보기 순서·조건·수치가 바뀌면 별도 문제로 유지한다.

예를 들어 기존2018년2회52번과 후기2024년1회50번은 신축이음 질문/보기와 정답③의 대응을 확인했다. 기존2018년2회70번과 후기2024년1회63번은 도시가스 배관 표시 항목과 정답②를 대조했다. 2021년1회1번과14번의 열역학 보기 순서 차이는 각각 보존했다. 수압시험은 압력용기/강철제 보일러와 단위·압력 조건이 달라질 수 있으므로 공식이나 정답만으로 합치지 않았다.

## 사용 화면

회차별 문제 → 에너지설비 중간고사. v5.8.2부터 첫 화면은 **시험범위3개 묶음114문제**와 **추가 예상만65문제**다. 각각 학습/CBT로 시작하고 아래4개 세부 묶음은 접힌 메뉴에서 고른다. 표의 수량은 계산을 모두 포함했을 때다.

전체179문제는 추가 메뉴에서 함께 풀 수 있다. 랜덤20은 두 모음을 합쳐 주제별1개씩 뽑으므로 추가 예상을 빼려면 시험범위만 버튼을 사용한다. v5.8.2의1~20번 주제 카드에서 계산 문제를On/Off하며 전체On/Off도 가능하다. 계산 분류22개는 집진율1/내부에너지11/상당증발량6/스케줄번호1/수압시험3개다. 숫자를 외우거나 공식만 고르는 문제는 수치 계산으로 분류하지 않았다. 6번·11번은On일 때 랜덤에서 계산 우선, 다른 주제의 계산도 포함 설정대로 뽑는다. 모두Off여도20주제 이론 연습이 가능하다. 새 풀이에만 적용하고 기존 이어풀기 답안·문항ID는 유지한다. 학습·CBT 번호 목록/OMR 계산 표시를 유지하고 교재91/PDF73는 추가 메뉴에서 선택한다. 수량은 계산 설정에 따라 줄어든다. 이 분류는 확정 출제 확률이 아니다. 특히 CO₂/매연 장치와pH/약품의 불명확한 받아쓰기는 직접 대응이라고 임의 확정하지 않았다.

## 이미지·해설

문제와 보기 전체를 PDF 원문 픽셀에서 분리했다. 문제 다음의 해설/정답 영역은 제외했다. Mac arm64 Real-ESRGAN x4plus-anime·타일256으로4배 처리하고2배 bicubic 축소 후 lossless WebP로 저장했다. 84개 자산과 로컬 원본 크롭/4배 중간 결과를 보존한다. 모델 출력이 원문 글자의 의미 정확성을 보증하지는 않는다.

다크모드는 기존 눈부심 완화 설정을 사용하며 라이트모드/원본 보기에서는 흰 바탕을 유지한다. 이미지 아래①②③④ 버튼을 사용하고 추측한 이미지 클릭 좌표는 만들지 않았다. 기존 학교 문항의 텍스트·보기·정답·ID를 보존했고 새 문항은 교재 정답표와 조건에 맞는 짧은 연습 해설을 넣었다.

급수 pH는 PPT/교재의 조건별 범위를 구분한다. 스케줄 공식은 같은 압력 단위이면1000P/S, P를kgf/cm²·S를kgf/mm²로 쓰면10P/S다. 수압시험의 다른 대상/조건을 한 공식으로 설명하지 않는다. 법규 전수 최신 검증은 이번 범위가 아니다.

## 경계 보완14개 — 반영 완료

자동 경계 확인에서 보류했던14개를 직접 확인하여 모두 반영했다. 2021년1회77번·2022년4회49번은 왼쪽 단 하단에서 오른쪽 단 상단으로 이어지므로 원본 픽셀을 읽는 순서대로 위아래 연결했다. 나머지12개는 질문·보기4개가 페이지 하단에 온전히 있으며, 해설이 다음 쪽에 있어 자동 경계 탐색이 실패한 경우다. 해설과 정답은 문제 이미지에 포함하지 않았다.

- 2021년1회77번, 2회60·62번
- 2022년1회6·24번, 4회17·49·74번
- 2023년2회52·63번
- 2024년1회25번
- 2025년1회23번, 3회13·53번

14개 출처는 추가 이미지로 보존하고, 질문·보기·정답이 완전히 같은 경우에만 기존 문항에 합쳤다. 11개 PDF 표시 문제를 새로 연결하고, 별도 문항6개를 추가하여 최종179개다. 가성취화의 보기 차이·상당증발량의 수치 차이·매연 문제의 보기 순서는 별도 문항으로 남겼다. 원본/업스케일14개를 검수표로 직접 봤으며 정답표를 대조했다. 기존 문제나 원본 PDF를 삭제하지 않았다.
