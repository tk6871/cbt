## 후속 보강: 기준 숫자의 출처

- 2023년3회 책1번:0°C는 얼음이 녹는 경계, -10→0은10°C 상승이라0-(-10)=10이며, 녹은 물은0→100이라100-0을 쓴다고 설명. 얼음·물 비열2.1/4.2 구별.
-36개 지문·대입식을 확인해 암묵적 숫자8곳을 기존 짧은 해설에 통합. 전체100%의1, 평균의2, 역수식의1, 원둘레의2·π·360, 그림위치①②③, 그림 엔탈피1630·545, 계수1.20·1.15와백분율100 포함.
- 최종23쪽/1,772,351바이트. 별도설명누적25쪽 중간본은 최종본이 아님. 모든 DIRECT/FORMULAS·답·반올림과원본그림·상세본·웹은 유지.
- 실제 검증: 생성기36지문·최종답/7책갈피/13우선/7미사용값·산술40건 통과.8출처ID/수식불변/그림10회픽셀동일/전체글자경계이탈0.23쪽 최종 렌더모음 및 대상3쪽 확대 확인·diff 통과.
- 웹·기기·APK·실물인쇄·원문 재수집전수 검증 미실행. 기존 도구만 사용. 커밋 후 GitHub Desktop Push origin, 다른 장치는 Pull.

## 후속 보강: 연산 이유

- 간단본36문제의 짧은 해설을 왜 곱하고·더하고·빼고·나누는지 한두 문장으로 보강했다. 비열·온도차·엔탈피차·혼합·효율·단위 환산·열저항·배수에 문항별 이유를 연결했다.
- 글자 크기를 줄이지 않고23쪽/1,772,811바이트. 아래22쪽 기록은 최초 간단본 결과이며 현재본은23쪽이다.
- DIRECT/FORMULAS 구조는 직전 커밋과 완전히 동일하고 답·반올림·문제·그림·상세32쪽은 변경하지 않았다.
- 실제 검사: 생성기의36문제/최종 답/7책갈피/13우선/7미사용값 및 산술40건 통과.36해설ID·수식 불변·그림10회 픽셀 해시 동일·전체 글자 경계 이탈0 확인. 최종23쪽 모음과 대표4쪽 확대 육안 확인, diff 검사 통과.
- 웹·APK·기기별 UI·실물 인쇄는 이번 PDF 보강에서 실행하지 않았다. 기존 도구만 사용하고 새 설치·다운로드·원본 자산 변환 없음.

## 완료

- 기존36문제·그림을 유지한 별도22쪽 풀이본 추가.
- 기본식, 한 번에 대입한 식, 답과 짧은 해설 순서. 곱셈식은 불필요하게 분수로 만들지 않음.
