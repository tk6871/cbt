# 필답 계산 PDF - 한 번에 대입하는 분수식

## 완료

- 기존36문제·그림을 유지한 별도22쪽 풀이본 추가.
- 기본식, 한 번에 대입한 식, 답과 짧은 해설 순서. 곱셈식은 불필요하게 분수로 만들지 않음.
- 풍량·냉동톤·전열면적·펌프 동력의 단위 환산과 표 합산을 식 안에 포함.
- 아주 긴 보일러 복합 문제만 Q1·Q2·Q3로 구분, 후속 계산에는 반올림 전 값을 사용.
- 기존 상세32쪽은 보존.8쪽 풍량 대입식만 최종 답과 같은 m³/h까지 연결.
- 기존 반올림 조건·최종 답·복원 조건 주의·원문 자산·웹 문제은행과 버전은 유지.

## 실제 검증

- 생성기:36문제 지문과 최종 답, 책갈피7개, 우선13개, 미사용값7건 포함 확인.
- 직대입 산술40건, 짧은 설명36개 ID 전체 포함 검사 통과.
- 두 PDF의 이미지10회 픽셀 동일, 전체 글자 페이지 경계 이탈0.
- 상세본의 HEAD 대비 텍스트 변경은8쪽뿐이며32쪽 유지.
- 최종22쪽 렌더 모음과 대표 계산식 확대 검수.
- 웹/UI/APK·실물 인쇄·모든 복원 원문 재수집 검증은 미실행.

## 재현과 인수인계

- 기존 Mac bundled Python과 설치된 ReportLab·pypdf·pdfplumber·Pillow·Poppler 사용.
- 데이터 내보내기 후 tools/build-practical-calculation-study.py --one-shot 실행.
- 기본 옵션은 기존 상세본을 생성. 새 설치·다운로드·이미지 변환 없음.
- GitHub Desktop Push origin으로 배포 저장소를 동기화하고 다른 장치는 Pull 후 작업.
