# 계산식 분수 표시 — v5.2.1 / 2026-10-21

필답형 계산 공부의 공식과25문제의 숫자 대입에 가로 분수선을 추가했다.
분자·분모가 뜻하는 값과 분모 전체를 묶는 계산 순서도 함께 안내한다.
나눗셈 없는 공식, 원문 문제·정답·기존 계산과정은 유지한다.

공유 수식 구조는 `src/cbt/practicalFractions.ts`에 있으며 웹은 기존 KaTeX,
PDF는 글꼴을 내장한 벡터 분수선으로 표시한다. 중첩 분수도 같은 구조를 쓴다.

PDF는31쪽으로 기존36문제와 관련 그림·기호·SI·단위·함정·반올림 조건을 유지했다.
공식 요약은 두 칸, 문제와 그림은 묶고 풀이를 이어 배치한다.
중간32쪽 전체 렌더 모음과2·3·4쪽 확대, 최종31쪽 끝 페이지를 직접 확인했다.

검사 결과:

- typecheck·production build·PWA610·버전 구분·diff 검사 통과
- 공통 공식 나눗셈 매핑, 모든 KaTeX 수식 렌더, 괄호/COP/펌프 산술 검사 통과
- PDF36문제·우선13개·실전 계산 슬롯 연결·그림 존재 검사 통과
- IAB4213에서 공식 분수와 COP 예제의12/3 대입 분수 확인

캐시가 남은4211에서 확인 중 선택 기능 오류가 발생해 최종 검사에 사용하지 않았다.
기존4205 사용자 화면/기록은 보존했다. 실제 기기나 APK 검사는 하지 않았다.
큰 청크와 Zod 주석 빌드 경고는 기존대로 남는다.

재생성은 다음 순서다:

1. `tools/export-practical-calculation-study.ts`를 esbuild로 Node 번들하고 실행
2. bundled Python으로 `tools/build-practical-calculation-study.py` 실행
3. Poppler로 PDF 렌더 후 확인

최종 PDF: `output/pdf/hvac-practical-calculation-study.pdf`.
