# 교재 차이·위험도별 묶음 검수

## 전환한 방식

- 이미 확인한 위치를 매번 다시 열지 않고, 남은 후보를 차이·위험도·범위·내용 묶음별로 모아 확인한다.
- 책 원문과 기존 CBT 원문/그림/네 보기를 좌우로8·12·20개씩 표시한다. 숫자·단위·문장 차이를 강조하되 OCR 차이를 실제 오류라고 단정하지 않는다.
- 정답/부정문 → 숫자/단위 → 그림/수식 → 문장/보기 → 다른 원문 탐색 순으로 분류한다. 주 분류끼리는 겹치지 않으며, 그림·수식은 다른 분류에 걸쳐 별도 필터로 확인한다.
- 확정 위치에는 현재 원본 해시 기준을 보관하고 이후 바뀐 위치만 재검토 대상으로 올린다. 처음 생성한 기준은 과거 검수 시점의 해시 증명이 아니다.
- 로컬 기록과 JSON 내보내기/불러오기를 지원한다. 번호·책 정답·직접 확인 표시가 없으면 동일로 기록하지 못하며, 원본 해시/후보가 다른 이전 결과는 적용하지 않는다. 공개 문제·정답에 자동 적용하는 기능은 없다.

## 사용

저장된 정상 열람 자료가 있는 Mac 저장소에서 실행한다.

```sh
node tools/build-hansol-batch-review.mjs
```

비교판은 `work/hansol-whole-book/batch-review/index.html`에 생성된다. 로컬 HTTP 서버를 통해 연다. 책 캡처·OCR·비교판·해시 기준은 Git제외이고 공개 배포하지 않는다. 다른 장치에서 작업하려면 해당 비공개 작업자료가 별도로 있어야 한다.

## 실제 검수와 남은 범위

- 시범8문항의 실제 책 지문·네 보기·그림과7쪽의 정답표를 직접 확인했다.
- 원문 유지3곳:2-62쪽10번,2-104쪽88번,2-260쪽15번.
- 교재 사본 입력5곳:2-98쪽62번,2-74쪽3·4번,2-92쪽30번,2-99쪽68번. 문장·기호 표기 차이를 기존 원본과 구분한다.
- 미검토1014→1006후보. 별도 보류21위치는 유지한다. 큐 안의 보류18개와 큐 밖3개를 혼동하지 않도록 집계를 보완했다.
- 수동 입력556행, 새확정 연결 준비325위치, 사본 준비281개, 인쇄 정답114칸. 공개 서비스는 기존1687연결/125사본이며 이번8건은 아직 렌더·공개 데이터에 반영하지 않았다.
- 분류는 오류 개수나 실제 책의 문제 총수가 아니다. 전체 교재 검수 완료·학술적 정답 인증을 뜻하지 않는다.

## 검증

- 순수 로직5검사: 우선순위·선택지 수식·값/단위 경고·안전한 차이 표시·원본 해시/후보/정답 검사 통과. 최초℃ 정규화 기대값1건을 실제NFKC 표현°C에 맞췄다.
- Chrome PC 전용 통합3검사: 큐 누락/중복0, 이미지 누락0, 재생성 일관성, 확정 전 확인 제한, 기록 저장/재개/내보내기/불러오기, 오래된 해시 거부 확인.
- 처음 시범8건을 처리한 뒤 빈 분류를 검사 대상으로 삼아 실패한2검사는 남아 있는 후보 대상으로 고쳐 재통과했다. 실패를 없었던 것으로 세지 않는다.
- 수동 입력/치환 문자열/기존 정답/그림 보존 검증556행·281사본 통과. 원본 은행·이미지·학습 기록·앱 소스 변경 없음.
- 새 설치/다운로드/촬영/대량OCR/업스케일/공개 UI 변경 없음. 앱 전체 빌드·휴대폰/태블릿 검사는 반복하지 않았고 공개 버전5.7/캐시622를 유지한다.
