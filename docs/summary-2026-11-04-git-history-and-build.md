## Summary

`과거 이미지 이력 정리 및 대용량 파일 목록 빌드 오류 수정`

## Description

- WebP로 대체한 옛 이미지17605경로와 퇴역29경로만 과거 이력에서 제거. 코드커밋222개와 최신파일 전체트리 유지.
- 복구용 전체이력은 Mac의 Git제외 work/private-notes/git-history-2026-11-04/backup.git에 보관. 정리본 packed데이터2.95→1.39GiB. 온라인 실제표시의 즉시감소는 보장하지 않음.
- APK준비 단계의 Git파일목록 버퍼초과를 스트리밍으로 보정하고 같은 목록읽기 위험의 감사도구도 수정.
- 오래된Actions런타임·가변Ubuntu기반·vue-demi미허용경고 정리. Zod설명주석만 호환보정, 유효PURE지시문/검증로직 유지.
- 회귀검사6개·웹빌드·PWA·Android동기화 성공. 타입검사는 신규선언파일 보정 후 재확인. 실제원격signed빌드는 아직 미확인.

## 장치 전환 주의

이력 반영 후에는 Windows의 이전 저장소에서 Pull/Merge/Push를 하지 않는다. 미커밋 변경은 별도 보존하고 새 clone을 사용한다. 원래 폴더를 바로 지우거나 Mac의 Git제외 원본/백업을 삭제하지 않는다.

## 후속

큰청크 성능경고 및 문제/해설 OCR전환은 별도 검증 후 반영한다. 원격강제푸시 결과는 WORK_STATE 최신기록에서 확인한다.
