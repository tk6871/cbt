# 2026-10-14 작업 요약 — v5.9.2

## 적용

- 기존 Vue UI를 유지하면서 PC 풀이 두 열을 최대1440px로 제한했다. OMR 포함 작업 영역은1728px, OMR 닫힘은1480px, 큰 글씨 한 열은900px다. FHD·4K에서 문제 카드가 계속 커지지 않으며 좁은 화면에서는 기존 한 열을 유지한다.
- 교재 문제/해설382장에768px 사본을 추가했다. 원본 합계74,068,030바이트 대비 사본32,339,052바이트로56.3% 작다. 테마27장192px 사본은80.9%, 이 중1장의640px 사본은65.7% 작다. 픽셀 밀도에 따라 원본이 선택될 수 있으므로 모든 휴대폰에서 이 비율만큼 트래픽이 줄어든다는 뜻은 아니다.
- 사본410개는 비율을 유지해 축소하고 lossless WebP로 저장했다. 흰색/검정 배경에서 디코딩한 모든 픽셀이 의도한 축소 결과와 일치함을 확인했다. 확대는 원본, 사본 로딩 오류는 원본 재시도다. 원문/정답/해설/좌표 파일은 변경하지 않았다.
- 화면 전환은 Vue의 이동/페이드 모션을 유지한다. 중복 실행하던 이전 화면 모션과 전체 화면 블러를 제거하고, 새 화면 전환 후 현재 보이는 최대16개 카드에 상세 모션을 준다. 창 크기 변경 중 답안 줄바꿈 측정은 프레임당 한 번으로 병합한다.
- 배포 CSS 기준으로 잘못 해석되던 테마 배경 변수의 상대 경로를 문서 기준 절대URL로 보정했다. 기본 테마나 사진 배치/인물은 바꾸지 않았다.

## 용량과 범위

원본을 보존하므로 저장소 용량 자체는 감소하지 않는다. 배포용 사본은33,443,428바이트(약31.9MiB)를 추가한다. 효과가 작은1280px 사본과 탈락한 변환물은 Git에서 제외한 `work/responsive-images-unused/`에 보존했다. 기존 개발도구·작업파일·Git 이력은 삭제하지 않았다.

이번 이미지 연결은 에너지 교재 문제/해설과 지원 테마 이미지다. 전체 종목/필답형 이미지 일괄 변환, 프레임워크 교체, 대규모 App.vue 분리는 포함하지 않는다. 추가 언어·도구 설치 없이 기존 Vue/TypeScript/Pillow로 처리했다.
