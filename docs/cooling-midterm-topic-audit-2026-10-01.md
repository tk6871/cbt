# 냉동공학 중간고사 소과목 분류 점검

## 범위와 한계

- 먼저 카탈로그의 과목 정보로 공조·한솔의 **냉동냉장설비**와 구 과목명 **냉동공학**을 모았다. `냉동장치의 구조`만 추출한 것이 아니다.
- 원본 1,920개 = 공조 1,380개 + 한솔 540개. 문장·보기·수치·정답·이미지까지 동일한 중복 45개를 뺀 전체 모음은 1,875개다.
- 그 안에서 사용자가 알려 준 여섯 소과목을 문제·보기·해설의 키워드로 임시 분류한다. 교재 목차의 실제 페이지와 전 문항을 대조한 확정 분류가 아니다.
- 소과목에 들지 못한 문제도 데이터나 전체 풀이에서 삭제하지 않았다. `분류 미확인`으로 따로 선택할 수 있다. 특정 소과목만 선택하면 이 문제들은 포함되지 않는다.

## 전체 자동 점검 결과

| 분류 | 원본 문항 수 |
|---|---:|
| 냉동이론 | 456 |
| 냉동장치의 구조 | 573 |
| 냉동장치의 응용과 안전관리 | 183 |
| 냉동냉장 부하계산 | 116 |
| 냉동설비의 설치 | 36 |
| 냉방설비운영 | 95 |
| 분류 미확인 | 461 |
| 전체 | 1,920 |

미확인은 공조 351개·한솔 110개다. 동일 중복을 뺀 미확인은 **451개**다. 원본 461개 중 주 텍스트에 분류 단어가 매칭되지 않은 경우는 386개, 여러 소과목의 최고 점수가 같아 유보된 경우는 75개다. 이미 분류된 문항까지 올바른 교재 소과목이라고 검증한 수치는 아니다.

샘플 텍스트 확인은 전 1,920문항의 원본 이미지 시각 검수나 교재 장별 판정이 아니다. 단어를 늘리는 것만으로 정확성을 보장할 수 없고, 보기에 다른 장의 단어가 있어 잘못 분류될 수도 있다. 기존 문제·정답·해설은 이 조사에서 변경하지 않았다.

## 권장 후속 확인

1. 교재의 여섯 소과목 목차·페이지 경계 및 핵심예상문제 페이지를 받는다.
2. 문제 문장·수치·그림으로 기존 문제와 대조한다. 복원 텍스트가 깨진 경우 원문 이미지를 확인한다.
3. 확정 분류와 자동 후보를 분리해 저장하고, 범위 밖 문항·미확인 문항도 따로 검토한다.
4. 그 전에는 시험 범위 누락을 막기 위해 전체 또는 미확인 문제를 함께 푼다.
