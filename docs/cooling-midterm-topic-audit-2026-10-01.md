# 냉동공학 중간고사 소과목 분류 점검

## v5.4.5 교재 목차 반영 후 점검

사용자가 제공한 교재 목차와 출제기준 사진을 함께 반영했다. 6번 이름은 사용자 확인대로 **냉방설비운영**을 유지한다. 선택 화면은 장 → 세부 목차의2단계이며 장 전체와 세부 범위별 학습·CBT·랜덤·오답·이어풀기를 지원한다. 반복 소과목 뱃지는 제거했다.

- 냉동이론: 냉동의 기초와 원리 / 냉매와 브라인 / 냉매선도와 냉동 사이클 / 각종 냉동 사이클 / 기초열역학 / 열역학의 법칙
- 냉동장치의 구조: 압축기 / 응축기 / 증발기 / 팽창밸브 / 부속기기 / 제어기기
- 냉동장치의 응용과 안전관리: 제빙·동결 / 열펌프·축열 / 흡수식 / 관련법규·안전관리
- 냉동냉장 부하계산: 냉동냉장부하 계산
- 냉동설비의 설치: 냉동설비의 설치
- 냉방설비운영: 목차의 냉방설비 설치와 출제기준의 냉동기·부속장치 유지보수, 냉각탑·수질관리

분류는 교재에 수록된 핵심예상문제를 직접 대조한 확정 결과가 아니다. 본문의 의미 단서를 보기보다 우선하며 본문/HTML 중복·띄어쓰기를 정리했다. 브라인은 이론, 열펌프·축열·흡수식은 응용으로 보완하고 부하 계산·냉매 충전·냉각탑 같은 명시적 문맥을 우선한다. 세부 목차는 하나의 범위만 식별될 때 배치하며 여러 범위가 겹치거나 단서를 찾지 못하면 세부 분류 미확인으로 남긴다. 일부 선도·열역학 법칙·냉각탑 표현은 구체적 목차를 우선한다.

장 미확인600개와 장 내부 세부 미확인202개는 서로 다른 집합이다. 이전451개보다 장 미확인이 늘어난 것은 보기나 포괄적인 단어만으로 단정하던 배치를 줄인 결과이며 누락·삭제가 아니다. 미확인도 장 전체·전체 풀이 및 별도 카드에 보존한다. 분류된 문항의 교재 장 적합성을 전수 의미 검수한 수치가 아니며, 서로 다른 해설을 가진 완전 중복 ID의 대표 선택 순서에 따라 장별 자동 후보 수가 일부 달라질 수 있다.

현재 냉방설비의 설치 세부 카드에는 자동 후보0개다. 책에 문제가 없다는 뜻이 아니라 현재 냉동냉장설비 문제 모음에서 확실한 표현을 찾지 못한 것이다. 텍스트가 손상되거나 여러 기기를 함께 묻는 문항은 원문/교재 페이지 대조가 필요하다. 정답·해설·문제·이미지·기존 ID와 저장 기록은 변경하지 않았다.

## 이전 v5.4 자동 분류 기록

아래 수치는 목차 사진을 반영하기 전 결과로 보존한다.

## 범위와 한계

- 먼저 카탈로그의 과목 정보로 공조·한솔의 **냉동냉장설비**와 구 과목명 **냉동공학**을 모았다. `냉동장치의 구조`만 추출한 것이 아니다.
- 원본 1,920개 = 공조 1,380개 + 한솔 540개. 문장·보기·수치·정답·이미지까지 동일한 중복 45개를 뺀 전체 모음은 1,875개다.
- 그 안에서 사용자가 알려 준 여섯 소과목을 문제·보기·해설의 키워드로 임시 분류한다. 교재 목차의 실제 페이지와 전 문항을 대조한 확정 분류가 아니다.
- 소과목에 들지 못한 문제도 데이터나 전체 풀이에서 삭제하지 않았다. `분류 미확인`으로 따로 선택할 수 있다. 특정 소과목만 선택하면 이 문제들은 포함되지 않는다.

## 권장 후속 확인

1. 교재의 여섯 소과목 목차·페이지 경계 및 핵심예상문제 페이지를 받는다.
2. 문제 문장·수치·그림으로 기존 문제와 대조한다. 복원 텍스트가 깨진 경우 원문 이미지를 확인한다.
3. 확정 분류와 자동 후보를 분리해 저장하고, 범위 밖 문항·미확인 문항도 따로 검토한다.
4. 그 전에는 시험 범위 누락을 막기 위해 전체 또는 미확인 문제를 함께 푼다.
