# 에너지설비 중간고사 교재판 — v5.9

## 사용 방법

회차별 문제 → 에너지설비 중간고사 → **풀기 전에 문제 출처 선택**에서 고릅니다.

- **에너지 교재 문제**: 기본값. 제공 교재에 실린 문제와 보기를 원문 이미지로 풀고 인쇄된 해설을 봅니다.
- **CBT + 에너지 교재**: 교재판에 기존 CBT 보강 문제를 더합니다. 동일 수록이 확인된 기존 문제는 교재판을 우선합니다.

선택은 주제별·전체·랜덤20과 새 풀이에 적용하며 저장됩니다. 진행 중인 풀이의 문항·답안은 자동 교체하지 않습니다. 교재판은 기존 답안 버튼으로 선택하며 새 이미지용 직접 클릭 좌표를 추정하지 않았습니다.

계산 기본은 6번 상당증발량·11번 스케줄번호입니다. 새로 확인한 13번 주제 계산도 기본에서는 제외하고 개별 On으로 켤 수 있습니다. 과거 기본 설정만 이전하며 전체 On 등 사용자 선택은 유지합니다.

## 이미지·해설 처리

- 원본 PDF SHA256: `840565d198cbbfe871b25a08e2bcb9b2d3dbdcbbadead2b2ca031308caed767d`
- 191문제 + 191해설 = 382장. 원본 스캔에서 질문/보기와 해설을 분리하고 두단·다음 쪽으로 이어진 부분은 연결했습니다.
- 기존 Mac arm64 Real-ESRGAN NCNN의 `realesrgan-x4plus-anime`, 타일256, 4배 처리 → 2배 bicubic 축소 → lossless WebP. 약71MB입니다.
- 원본 크롭과 4배 중간 결과는 Git 제외 작업 폴더에 보존합니다. 새 도구 설치·다운로드는 하지 않았습니다.
- 문제와 해설 모두 다크 눈부심 완화·라이트·원본 표시 설정을 따릅니다. 창 크기 변경 중에도 해설 다크 필터를 유지합니다.
- OCR은 원문 위치를 찾는 보조 수단입니다. OCR로 다시 쓴 문제/보기를 화면에 내보내지 않습니다. 해설도 인쇄 원문 이미지이며 AI 해설로 표시하지 않습니다.

2025년2회45번의 증발계수 단위 오기, 2025년2회52번/3회60번의 반대 조건은 주의 문구로 구분합니다. 교재 정답을 임의로 바꾸지 않았으며 역화 관련 두 해설의 일관성은 추가 확인이 필요합니다.

교재634쪽 전체 시각 검수·1680문항 전체 사실 검증·출제 확률 보장이 아닙니다. 일부 크롭 주변에 작은 여백/다른 단의 흔적은 남을 수 있으며 원문 글자를 AI로 복원했다고 주장하지 않습니다. 일반 에너지2021~2025년1040문제 전체 추가 및 필답형 이미지 업스케일링은 별도 남은 작업입니다.
