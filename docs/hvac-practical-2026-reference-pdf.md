# 2026년 1·2회 공조 필답형 해설 PDF 교체 기록

## 적용 범위

- 사용자가 제공한 2026년 1회 10쪽과 2회 8쪽을 모두 화면으로 확인했다.
- 기존 24문항의 ID는 변경하지 않아 작성 답안·오답·진도 기록이 유지된다.
- PDF에서 개인 식별 문구·QR·전체 쪽을 저장하지 않고 학습에 필요한 문제 그림 18개와 답안 그림 7개만 분리했다.
- 2026년 1·2회에 쓰던 기존 영상 캡처 25개는 제거했고, 실행 중인 문항은 PDF 그림만 참조한다.

## 원문 대조로 바뀐 내용

- 2026년 2회 11번을 PDF 원문의 `액순환식 증발기 / 리키드백(액압축) 방지`로 교정했다.
- 2026년 2회 1번은 정회전·역회전 모두 GL이 점등 상태를 유지함을 풀이에 명확히 적었다.
- 2026년 2회 12번은 스크롤 압축기의 고정·선회 스크롤 사이 체적이 줄며 압축되는 순서를 보강했다.
- 문제용 그림에는 정답 문장이 노출되지 않도록 표·회로·사진 영역만 잘랐다. 답안용 그림은 답안 확인 후에만 보인다.
