# 교재 교재 개별 대조 진행 요약

## 이번 진행

- 교재 전용 독립 풀이 화면과 목차 팝업은 사용자가 커밋한 상태를 그대로 보존했다.
- 기존32개 검토 이후285개 후보를 실제 교재 화면과 기존 문장·문제 이미지·도식·보기·해설/정답표로 개별 대조했다.
- 그대로 연결156개, 교재용 사본 차이123개, 추가 보류5개, 번호 확인1개로 기록했다. 그림후보 중 또 다른 번호 오독도 실제 번호로 보정했다.
- 현재 추가 확정 준비306위치, 교재용 사본 준비271개, 직접 전사한 정답102칸, 번호 보정11건이다. 이 수치는 공개 반영 수와 다르다.

## 실제 검증

- 수동 입력532행의 원본 문항 존재·정답 일치·치환 문자열 정확성·문항 키 중복 검증을 실행해 통과했다.
- 입력을 반영한 검토 큐를 재생성했다. 근접 후보0개, 그림207개, 전체 대조823개가 미검토로 남는다. 검토했지만 미확정인14개는 별도다.
- 공개 문제 데이터·새 사본 렌더·production build·기기 화면 검증은 이번 입력에 새로 실행하지 않았다. 이전 통과 기록을 이번 결과로 재사용하지 않는다.

## 아직 완료하지 않은 것

- 전체 개별 검토는 미완료다. 남은 후보1030개를 이어서 직접 확인해야 한다.
- 공개 데이터는 기존1687연결/125사본을 유지한다. 추가146사본은 아직 이미지 생성·좌표·공개 데이터 반영 전이다.
- 모든 검토와 최종 통합 검사 이후 버전/캐시 갱신과 커밋이 필요하다. 이번에는 커밋·Push하지 않았다.
- 기존 문제은행·원본 이미지·사용자 학습 기록은 변경하지 않았다. 사적 책 캡처와 OCR은 Git 제외를 유지한다.
