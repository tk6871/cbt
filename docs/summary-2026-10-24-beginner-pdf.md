# 계산 PDF 전체 초보자 설명

사용자가 한 예제가 아니라 PDF 전체의 설명 수준을 바꾸려는 뜻임을 확인하고 상세본 전체를 다시 편집했다.

- 숫자의 뜻→왜 더하고 빼고 곱하고 나누는지→숫자 계산→글자식·분수·단위 연결 순서.
- SI/단위2쪽, 숫자·비율·이항·CGT/COP/BF/엔탈피/제곱3쪽, 전체36문제 해설 재작성.
- 1 kg당 열·1 m³당 열·초당 양·효율·온도차·배수의 뜻을 계산 옆에서 설명한다. 원문에 없는 환산수/그림에서 읽은 수의 출처와 필요한 이유를 설명한다.
- 기존36문제·최종 답·그림10회·미사용 값7건·책갈피7개·반올림 예외·복원 조건 경고 유지. 문제은행/웹 해설/별도1쪽 요약 수정 없음.
- 30→32쪽(1,867,689바이트), 본문11pt 유지. 공식은 말 설명 뒤에 배치하고 유형 제목을 문제 상자에 포함했다. 마지막 대입식과 답을 묶었다.

## 실제 검사

- 생성기36문제 지문/기존 최종 답 포함 검사, 새 해설36개 ID의 완전 일치 검사 통과.
- 실제 계산40건 산술 대조 통과. 원문 전체를 새로 수집해 재검증했다는 뜻은 아니다.
- 기존 PDF의 그림10회 삽입 픽셀 해시 일치, 최종32쪽 글자 페이지 밖 이탈0, 책갈피7개.
- 최종32쪽 PNG 렌더 모음 확인, 기초·일부 유형 확대 확인. git diff --check 통과.
- 실물 인쇄·웹 빌드/기기별 UI·APK 검사는 PDF 전용 작업이라 미실행. 중간33쪽과 제목 묶기 실험은 최종본이 아니다.

## 재현과 인계

기존 bundled Python으로 tools/build-practical-calculation-study.py 실행. 기존 tmp/pdfs/practical-calculation-study.json을 읽는다. 새 편집 해설은 tools/practical_beginner_solutions.py, 기초는 tools/practical_beginner_primer.py. 이전 편집 파일들은 보존했다. 새 설치/원본 이미지 변환 없음.

시작 main/origin 일치·깨끗함. 웹5.3.2/캐시613은 그대로. 커밋·Push 후 다른 장치에서 Pull한다.
