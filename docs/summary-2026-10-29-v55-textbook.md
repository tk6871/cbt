# v5.5 교재 페이지별 풀이·에너지 COMCBT 해설

## 적용한 것

- 회차별 문제 → 교재 페이지별. 한솔 공조/에너지 교재, 인쇄 쪽번호와 교재 문제 번호, 이전/다음 쪽과 범위 학습/CBT.
- 확인된 좌우 열을 PC에 배치하고 좁은 화면은 한 열로 유지한다. 4K에서도 내용 폭은1500px 이하로 제한한다.
- 교재별 선택 쪽과 별도 풀이ID를 저장한다. 일반 기출·중간고사 원본 문제/기록은 덮어쓰지 않는다.
- 에너지의 실제 COMCBT 수집 해설을 지문·4보기 순서·정답 대조 후 우선 표시한다. 원본 교재 해설은 접어서 보존하고 기존 작성 설명도 추가로 남긴다. HTML 화살표 기호는 읽을 수 있게 표시한다.
-316풀이ID: 후기176, 기존 일반30, 교재 중간61, 기존 중간49. 중복 기록용 ID가 포함되어 서로 다른316문제라는 뜻은 아니다. 원문·대상 fingerprint가 바뀌거나 답/출처가 다르면 적용하지 않는다. 이미지 대상 SHA를 자동 검사하며 동일 번호지만 원문 픽셀이 다른15개는 추가 제외했다. 실제 등록 해설988개를 후보로 썼으며 AI 설명을 COMCBT로 바꾸지 않았다. 사이트 최신 실시간 재수집이나 해설 내용의 사실 보증은 아니다.

## 아직 안 끝난 범위

- 두 교재 전체가 대상이다. 한솔 단원 핵심/실전예상문제·핵심 모의고사·뒤쪽 기출도 포함한다. 현재는 한솔151쪽594위치 중367개 연결, 에너지249쪽1,135위치 연결만 제공한다. 미대조 쪽은 명시적으로 안내한다.
- 한솔 전체 정상 앱 열람 대조, 에너지 이론편 예제 확인과 구회차640문제 연결은 남았다. 현재 연결분만으로 전체 교재 완료라고 하지 않는다.
- 구회차640문제의1,280개 원문 이미지 변환은 끝났다. 수정한2018-4-52의2장 재처리 후 전체source/output SHA·2배 크기·tile256/arm64 오류0이다. 좌표609/640,31개 보강과 수정된52번 새OCR이 남아 미연결 자산은 Git 제외로 보존했다. 새 은행에 포함했다고 하지 않는다.
- 교보의 임시 가로 두 쪽 보기는OFF로 복원했다. 캡처 허용·보안 설정은 바꾸지 않았다. 전체 eBook 화면/해설을 대량 복제하지 않으며 기존 CBT의 쪽번호 연결을 진행한다. 제공된 에너지 PDF 문제·해설 변환과 구분한다.
