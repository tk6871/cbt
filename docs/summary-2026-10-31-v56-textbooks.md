# v5.6 교재 쪽별 풀이·전체 자동 대조 결과

## 반영 범위

- 한솔 정상 열람620화면·열별OCR2,480영역·인쇄쪽1,176곳을 전체 자동 대조했습니다. 한솔604쪽1,915등록 위치 중1,687위치를 기존 CBT에 연결했습니다. 이 수는 고유문제 수가 아닙니다.
- 남은 후보1,362건에 관련된 기존 이미지1,529장을 Mac의 로컬 Vision으로 새로 읽어 비교했습니다. 네 보기 인식이 완성된 이미지는1,119장입니다. 엄격한 일치 후보6곳은 실제 교재/기존 이미지를 직접 보고 추가 연결했습니다. OCR 본문이나 교보 캡처를 문제은행으로 배포하지 않습니다.
- ‘교재 페이지별 → 전체 자동 대조 현황’에서1,176쪽을 검색하고 연결·미확정 인식 후보·출제 보류를 구분해 해당 쪽으로 이동합니다. 한 번에80쪽씩 표시해 휴대폰의 초기 표시 부담을 제한합니다.
- 교재 원문 이미지의 실제 PNG/JPEG/WebP 크기를 읽어 미리 자리를 예약하고 기존 크기 정보도 보존합니다. 정정 PNG의 소수 CSS높이와 실제 픽셀높이의1px 반올림 차이도 실제 PNG 기준으로 통일하고 좌표 비율을 맞췄습니다. 이미지 내용을 재압축하거나 원본을 바꾸지 않습니다.
- 직접 대조한125개 교재용 정정 사본에4보기 직접 선택 영역을 제공합니다. 기존 문제은행·정답·원본 이미지·기존 해설·배포된 학습ID를 보존합니다. 교재 사본의 정답 차이7건만 분리 채점하며, 시험 중 정답이 포함된 대조 안내는 숨깁니다.
- 수식·정답표·보기 조건이 충돌하는8건은 사유와 함께 출제를 차단합니다. 면적A 유무와kJ/h·kcal/h, 가습/감습, 효율낮다/높다, 복수정답 등의 차이를 같은 문제로 뭉개지 않습니다. 펌프 배관도는T/S기호·밸브·지시문자까지 확인했습니다.
- 에너지2018~2025년21회차1,680고유문항/320쪽1,709위치를 제공합니다. 앞서 처리한 구회차640문제의 문제/해설1,280장과 좌표를 연결하고 기존72문제 기록ID를 유지했습니다. 일반 CBT·중간고사 선별 목록은 변경하지 않았습니다.
- 에너지 이미지에는 기존 Mac arm64 Real-ESRGAN x4plus-anime·타일256·4배→2배 bicubic 결과를 사용합니다. 동일144장은 재사용하고 새1,136장 약199.5MiB를 반영했습니다. 원본·다크·라이트·직접 선택을 유지합니다. 대량 GPU 처리를 새로 반복하지 않았습니다.
- 에너지의 COMCBT 우선 해설566개 독립 풀이ID와 원문 해설을 보존합니다. 본문88~89쪽 예제는 별도 문제/풀이로 제공하며 객관식에 넣지 않습니다. 답89.125TOE의 산술을 확인했습니다.

## 검증

- 최종v5.6/캐시621의타입·production build·PWA·패치노트 식별 검사 통과. 기존 큰청크·Zod 주석 경고는 유지됩니다.
- 이미지 크기 보완까지 포함한 최종45검사를2.3분에 모두 통과했습니다. PC/휴대폰/태블릿 크기에서 교재 선택·쪽 이동·기록 분리·이어풀기·정답 비노출·원본 보존·다크/라이트·목차·대조 현황 검색/보류 안내를 확인했고, 에너지1,680문제×4보기의 선택/취소/강조 영역도 전수 검사했습니다. 처음 정적 서버에서 개발 전용 좌표 하니스를 실행한6실패는 Vite 서버로 분리하고 준비 상태 조건을 수정한 뒤 전체 재검사하여 통과했습니다.

- 대조 현황을 화면 안으로 스크롤한 추가3개 동선 검사는14.5초에 통과했고 PC/휴대폰/태블릿 크기 캡처도 확인했습니다.
- 구조 감사44,910문제·12,210이미지 참조의 구조 오류·누락 이미지·중복 정답 충돌0을 이번에 재확인했습니다. 별도 정답/해설 검토 후보19건은 남습니다. 이는 학술적 사실 전수검증이 아닙니다.

## 남아 있는 제한

전체 화면의 자동 대조는 끝났지만 모든 문항의 육안 확인·연결이 끝난 것은 아닙니다. 현재 미확정 인식 후보1,348건과 출제 보류8건이 있으며, 후보 수는 실제 책의 문제 수나 미수록 수가 아닙니다. 수식·도면·불완전 인식·기존 은행에서 찾지 못한 문항은 임의로 확정하거나 다른 문제로 대체하지 않습니다. 교재의 추가 본문 예제도 전부 수록한 것으로 표시하지 않습니다.

구 작업 체크포인트는 [이전 진행 기록](summary-2026-10-30-v552-textbooks.md)에 남깁니다. 최종v5.6 상태는 이 문서와WORK_STATE.md의 최신 항목이 우선합니다. 사용자 요청에 따라 변경 파일과 이 요약을 함께 커밋하며, Push/배포 여부는 Git 결과에 따라 별도로 보고합니다.

새 설치·다운로드·압축·이미지 경량화·원본 삭제는 없었습니다. 교보 앱은 두쪽 보기OFF·원래 창·읽던80% 복원 상태를 유지했고 이번에 앱/권한을 다시 조작하지 않았습니다. 대조용 캡처·OCR·컴파일 캐시는 Git에서 제외합니다.
