# v6.0 이미지 OCR 확대와 첫 화면 경량화

## Summary

`v6.0: 이미지 문제·해설 OCR 확대 및 첫 화면 경량화`

## Description

- 이미지 지문·해설 7,098개 경로를 조사하고 중복을 제외한 7,095장을 판독·픽셀 검사했습니다. 문제 1,674개·해설 302개에 텍스트 전환을 연결했습니다.
- 원문 표본 12개를 직접 비교해 11개 전사를 보강하고 수식 오인식 1개는 이미지로 유지했습니다. 총 확인 전사 13개 외에는 임시 OCR입니다. 나머지 5,122경로는 이미지가 기본이며, 전체 육안 검수는 아닙니다.
- 교재 데이터와 임시 OCR을 필요할 때만 불러옵니다. 정답·선택 좌표·저장 ID·원본 이미지는 유지하며 OCR을 불러오지 못해도 원문으로 풉니다.
- PC 첫 화면 JavaScript 5.82→2.96MB, gzip 1.20→0.87MB. 파일 의존성 기준이며 과목 은행·CSS·선택 기능은 제외합니다. PWA는 실제 빌드에 맞춰 오프라인 파일을 선택합니다.
- 타입·빌드·PWA·원문 매핑, PC/휴대폰/태블릿 모사, 교재 이어풀기·오프라인 앱 화면·Android 웹 번들을 확인했습니다. v6.0은 로컬에서 검증했으며 원격 배포·신규 서명 APK는 아직입니다.
