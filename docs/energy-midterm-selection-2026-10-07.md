# 에너지설비 중간고사 선별 기록

## 자료의 성격

처음 보낸 텍스트는 사용자가 교수님 설명을 듣고 쓴 메모이고, 마지막 2쪽 PDF는 다른 사람이 정리한 메모다. 둘 다 확정 시험지나 교수님이 직접 작성한 출제 목록으로 취급하지 않는다. 두 메모의20주제를 교수PPT와 제공 교재의 관련 내용에 대조하여 최초47문제를 선별하고 관련 유형89문제를 보강한 현재 연습 모음은136문제다. 일반 기출 데이터와 정답은 수정하지 않았다.

20은 실제 시험의 문항 수이지 예상문제 은행의 제한이 아니다. 원문 단어 검색 결과를 그대로 넣지 않고 질문·보기·단위가 주제에 맞는지 읽어 선별했다. 증기트랩과 배수트랩, pH와 영어phase/sphere, 응축수 환수와 이온교환수지처럼 단어만 겹치는 후보와 식·조건이 빠진 후보는 제외했다. 질문·보기·정답·그림의 동일 서명은 추가하지 않지만 표현·보기 순서·수치가 다른 유형은 연습에 유지한다. 최초47개 학교 문항 ID는 유지한다.

기존 에너지관리산업기사 데이터는33회차·2640문제(2002~2020)다. 주제·보기 검색 후 선별 문항의 질문과 네 보기를 읽고 원문 저장 정답을 대조했다. 특히2018년2회와 주제가 많이 겹치지만 그 회차가 그대로 출제된다는 근거는 아니다. 새2020년 이후 산업기사 기출 수집은 후속 작업이다.

## 주제별 첫 선별 문항의 원문 대응

## 직접 대응과 추가 예상

사용자는 두 메모의 주제가 교수님이 출제를 안내한 범위라고 확인했다. 다만 메모는 받아쓰기이며 기출 그대로 출제되는지는 확인되지 않았다. 질문의 주된 판단·계산이 메모와 맞는83문제를 ‘직접 대응’, 같은 주제의 다른 판단이나 불명확한 내용을 넓혀 연습하는53문제를 ‘추가 예상’으로 나누었다. 문제 수·학교ID·기존 정답은 유지했다. CO₂/매연 장치와pH/약품은 질문 의도가 불명확하여 추가 예상으로 남겼다. 직접 대응은 출제 확률 수치나 정답 예측이 아니다.

교재 원문 대응27문제는 별도 기준이다. 책에 같은 기출이 실려 있다는 사실과 출제 메모에 직접 대응한다는 판단은 다르므로 교재 확인 문제도 추가 예상에 포함될 수 있다. 화면에서 두 모음을 따로 학습하고, 전체·교재·랜덤 연습은 접어서 표시한다.

## 자료 대조와 불확실성

- 사용자가 교수님 수업 때 실제 사용하는 PPT임을 확인했다. 수업PPT6개382장의 텍스트·수식XML을 읽고20주제와 연결되는 슬라이드 번호를 기록했다. 모든 그림을 시각 검수한 것은 아니다. 스케줄번호는PPT텍스트에서 직접 확인하지 못했으므로 교재345쪽을 근거로 구분한다.
- 새307쪽PDF는 이론 부분이다. 새PDF307쪽과 기존 전체 교재의 뒤쪽327쪽을 로컬 Apple Vision으로 OCR하여 후보를 찾았다. 총634쪽 OCR은 전수 시각·정답 검증이 아니다. 교재336~349쪽의2018년2회24문항,354쪽STC26번,375쪽트랩62번,384쪽상당증발량25번은 렌더링에서 질문·보기·정답(해설 또는 정답표)을 직접 대조한27문항이다. 교재260쪽pH도 직접 확인했다. 원본·OCR 전문은 공개 저장소에 넣지 않았다.
- 교재 대응표와 슬라이드 근거는 `tools/energy-midterm-references.mjs`에 기록하고 선별JSON/문제 출처표시에도 연결한다. 책 전체 기출을 새로 추가한 것은 아니며, OCR유사도만으로 대응 확인을 표시하지 않는다.
- 상당증발량은 PPT의2257 kJ/kg과2018년 기출2256 kJ/kg을 반올림 차이로 구분했다. kcal/kg의539는 표준 증발잠열이라는 의미도 해설에 설명했다.
- 급수pH는 수업PPT2-1/2-2의57장에6~9(적정8.5), 관수는11~11.8이다. 교재260쪽은 급수6.5~9·관수10.5~11.5로 다르므로 수업 기준을 우선 확인하도록 둘을 분리했다. 메모의6.92와 첨가제 이름은 미확정이며 과산화수소로 추정하여 가르치지 않는다. 해당 숫자 범위와 직접 대응하는 기출을 찾지 못해 관수 약품 기출은 관련 연습으로 표시한다.
- 2018년2회67번 수압시험 해설은 교재347쪽에 따라30분·6%초과 제한을 설명한다. 보기④는10%제한을 써서 틀린 것이다. 기존의 모호한 ‘10%까지 초과하도록’ 표현을 교정했고 원문 정답④는 유지한다.
- 배관 고정은 교재309쪽/PPT에13미만1 m,13~33은2 m,33이상3 m로 표기되어33에서 경계가 겹친다. 교재mm와PPT A 표기 차이도 있어 안내만 제공하고 임의로 확정 문제를 만들지 않았다. 표시 사항은 교재310쪽과 기출이 대응한다.
- 보염장치와 윈드박스, CO₂가스분석과 수트블로워는 다른 개념이다. 두 메모의 불명확한 표기를 같은 장치 이름으로 합치지 않았다.
- 응축수 환수는 증기난방 분류이다. 보일러 자체의 형식으로 잘못 표기하지 않았다.
- 수압시험·설치 기준은 제공 교재와 구 기출의 연습이다. 현행 법규 전수 확인을 했다는 뜻이 아니다.
- 2017년4회21번은 ‘다음 식’이라고 하지만 저장된 식이 없어 이번 선별에서 제외하고 조건이 완전한2019년2회25번 계산 문제로 바꿨다. 2016년2회49번의 개인영역 깨진 문자는 학교 모음에서만 제거했다.
- 안정적인 녹음 복사본122.253초는 보존했다. 기존 Mac 캐시의 MLXWhisper 모델로 받아쓰기를 시도했지만 작은 음량과 반복 환각으로 신뢰 가능한 전체 자막을 얻지 못했다. 일부 배관 관련 말 외에는 녹음을 확정 근거로 사용하지 않았다. 음성 외부 전송 없음. 원본 녹음과 교재·PPT·메모 원본은 공개 저장소에 넣지 않는다.

## 구현 범위

회차별 문제의 ‘에너지설비 중간고사’와 종목 선택에서 접근한다. 교재 대응27문제·전체136문제 학습과 주제별 학습/CBT, 각 주제에서 랜덤1개씩 고르고 순서도 섞는20문제 학습/CBT(연습30분)를 제공한다. 문항 ID는 `school-energy-`로 시작하므로 일반 에너지 기록과 분리되며 주제 연습과20문제 시험 사이에는 같은 학교 문항 ID를 사용한다. 새로운 서버·인증·동기화 스키마는 없다.

현재136문제는 기존 CBT 텍스트·수식형이며 OCR로 새로 전사한 문제는 아니다. 이미지 참조0개다. 사용자 요청의 제공 PDF 원문 이미지 연결·업스케일링·이미지 다크/라이트 검증은 아직 미적용이며 후속 작업이다. 자료 OCR은 후보 탐색에만 사용했으며 화면에 OCR 전문을 게시하지 않았다. 기존 원본·업스케일 파일은 유지하고 라이트·다크 화면 설정을 사용한다. 전체 일반 기출의 사실 검증, 실물 기기 동기화,2020년 이후 신규 기출 추가도 이번 완료 범위가 아니다.
