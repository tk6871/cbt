## 주요 수정 및 근거

- 펌프: 잘못된 `(N₂/N₁)=(H₂/H₁)²=(P₂/P₁)³`, `N2=91.8*800`, `1.8/1.5*80=96`을 교정. 같은 지름·상사조건에서 `N₂=800×1.8/1.5=960rpm`, `H비=N비²`, `P비=N비³`. 실제로 읽은 공식 EnergyPlus 압력 해석 소스와 펌프 동력식을 대조하고 독립 재계산했다. 원문 스캔5개 중 해당하는4개와 기존2015 텍스트 지문·보기를 확인. 동일값 연결문항5개를 모두 기록했다.
- 에어와셔: 일반 습공기선도 설명 대신 정상 열수지에서 `L/G=(i₁-i₂)/[c_w(t_w₂-t_w₁)]`를 유도. 비열의 수치가1인 kcal계와 kJ계를 구분하고 열이동 방향을 설명했다. 저장 정답① 유지. 독립 열수지 계산은 sources에 공개했다.
- 저항: 120Ω4개에 전압을 가정하여 가지 전류를 합산, 병렬 등가30Ω·직렬480Ω을 독립 계산했다. 복원 원문의 충분한 주 해설은 유지하고 연결된 일반론만 고쳤다.
- 교재1-182쪽79번: 원문도 ‘중간기 엔탈피차가 작아서’라고 설명하나, 외기냉방에 유리할 때 불필요한 열회수를 막는 것이 핵심이다. 공식 EnergyPlus 열교환기 문서의 economizer 운전시 열교환 중지·바이패스 항목을 직접 읽어 적용 조건을 구분했다. 원문 풀이 이미지는 그대로 남겼다.
- 에너지 교재336쪽1·2번,350쪽3번: 원문을 직접 열어 확인했다. 각각 전기식의 낮은 압력손실, 사이클론의 원심력 분류, 건식 중 백필터에 관한 전사다. 표 전체나 판독 불확실한 수치는 옮기지 않았다. 학술 검증 보류 상태로 분리했다.
- 과거 추가 해설 후보6건: 실제 출처는 모두 해당 공조 문제와 대응한다. 감사 코드가 다른 종목의 같은 연도·회차·번호로 ‘공조 복원’ 출처를 덮어썼다. HVAC 출처만 색인하고 NFKC 표기를 정규화했다. 변경 전 은행에 수정된 감사만 적용해도6건이 사라짐을 확인했다. 서로 다른 원문이 실제로 같은 이름을 쓰는 경우는 예외를 발생시키며 검사 기준을 낮추지 않았다.
