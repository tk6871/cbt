## 결과

- 중복25개는 이미 새 출제에서 제외되어 출제 대상154개다. 계산 기본6/11 설정 적용 시139개다.179개는 과거 풀이 복구용 원문 수로, 중복이 다시 출제되는 뜻이 아니다. 보고서도 기본은154대표만 표시한다.
- 기존 원문 수록 근거91개에 이번 동일 문항 확인28개를 더해, 기록용179ID 중119개에 수록 근거가 있다.
- 이미 통합한 중복25ID를 제외한 **현재 대표154개 중 확인100개·미확인54개**다. 계산 설정으로 일부를 끈 기본 출제139개와는 다른 집계다.
- 최초 미확인88개의 분류는 동일 문항28·관련 변형33·이론/해설 대응15·동일 수록 미확인12다. 이후179개 전부를 질문·보기 기준으로 역대입하고 기존91개까지 원문 재확인했으며 엄격한 동일 수록 수량은119ID로 유지했다. 기록용 미확인은60ID다. 미확인은 ‘책에 없다’는 뜻이 아니다.
- 질문·수치·단위·네 보기 내용이 같고 보기 순서만 바뀐 경우는 확인했다. 다른 수치·질문 대상·틀린 보기, 본문/해설에만 있는 설명은 동일 문항 수록으로 확정하지 않았다.

예를 들어2015년4회54번 보염장치 문항은 원문에서 ‘대류형’, 교재 PDF621쪽13번에서는 ‘평행류형’이 틀린 보기다. 개념이 같아도 같은 객관식 문항으로 승인하지 않았다. 2013년1회64번 스위블 문제도 원리·정답 개념은 같지만 질문 축약과 루프/신축곡관 보기 표기 차이를 별도 남겼다. 기존 중복 승인이나 정답을 이번 조사로 되돌리지는 않았다.

## 대조 방법과 한계

- 원본은634쪽 전체 스캔이다. SHA256: `840565d198cbbfe871b25a08e2bcb9b2d3dbdcbbadead2b2ca031308caed767d`.
- Mac의 기존 Apple Vision으로634쪽 검색 보조 자료를 만들었다. 질문/보기 문자 겹침으로 페이지 후보를 찾았으며 OCR점수 자체로 수록 판정을 내리지 않았다. 수식·절댓값·단위 차이는 원문과 대조했다.
- 최초 미확인88개의22시트 검토에 이어, 원문179개 모두를634쪽 검색 창41912개 및 문제 단위 후보1672개에 역대입했다. 질문만/보기만/질문+보기 검색 결과를 따로 검토했다.1672는 OCR로 잡은 검색 단위 수이며 책의 실제 문제 총수라는 뜻은 아니다.
- 수록 근거119개의 기록된 질문·보기 원문과 미확인60개의 기록 후보·별도 검색 후보를60검수 시트로 직접 대조했다. 가성취화77번처럼 왼쪽 아래에서 오른쪽 위로 이어지는 경우는 전체 페이지를 추가 확인했다. 기존91개도 이번에 원문 재확인했다. 각179행에 직접 대조 여부를 기록했다. 같은 질문이라도 틀린 보기·수치가 다르면 승인하지 않았다.
- **634쪽 전체를 눈으로 읽은 전수 검수, 모든 문항의 정답 사실/현행 규정 검증, 미확인 문항의 부재 증명은 아니다.** 비슷한 문장·같은 정답만으로 같은 문항이라 단정하지 않는다.
- 대장의 페이지는 PDF첫 장을1쪽으로 센 위치다. 인쇄 쪽수와 다르다. 미확인 행의 페이지는 비교 후보/이론 위치이지 해당 문제의 수록 증거가 아니다.
- 대조 화면은 기존 앱 질문·보기·이미지만 표시한다. 사용자 교재 PDF/스캔 페이지/OCR 전문은 저장소에 공개하지 않는다.

## 재현과 검사

- `node tools/review-energy-book-scope.mjs`: 공개 가능한 수록 대장과 검토HTML 재생성. 현재 문제은행 SHA256이 바뀌면 이전 판정을 자동 재사용하지 않고 중단한다. 로컬 PDF/OCR 없이 재현 가능하다.
- 검색 자료 재생성은 `tools/ocr-energy-book-pages.swift`(Mac PDFKit/Vision), `tools/match-energy-book-scope.mjs`, `tools/render-energy-book-review.py`(기존 Poppler·Pillow)를 사용한다. 개인 PDF는 사용자 로컬에서 지정한다. 작업 캐시는 Git제외 `work/energy-book-scope/`다. OCR은 원문 대체용이 아니다.
- 전체179개 재대입 도구는 `tools/compare-energy-book-all.mjs`, `tools/index-energy-book-questions.mjs`, `tools/render-energy-book-all-review.py`다. 기존 OCR/원본 해시를 확인하고 검색 후보와 비공개 검수 시트를 만든다.
- 수록 대조와 후기 패턴의 관련PC4검사 통과:179ID/원문해시/정답/페이지·100/54집계·직접 대조 기록·1040슬롯/13회차/18수동 사례·판정/검색 필터·기존 원문 이미지 로딩·가로넘침·저장값 보존·브라우저 오류0. 최종 캡처를 직접 확인했다.
- Node구문·Python AST·원본 해시·생성기 재실행 JSON/HTML 바이트 동일성·diff검사를 확인했다. 기존 OCR/렌더 캐시는 원본PDF해시가 다르면 재사용하지 않는다. 이번에는 새 OCR/Swift컴파일을 실행하지 않았다. 앱변경이 없어 typecheck/build/PWA/APK·휴대폰/태블릿 전체 검사는 실행하지 않았다.
