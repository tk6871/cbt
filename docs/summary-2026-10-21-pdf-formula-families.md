# 계산 PDF 유형별 정리

- 기존39쪽에서34쪽으로 정리했다. 글씨를 줄여 맞추지 않고, 별도 요약/우선 공식 설명과 중복된 기호 안내를 해당 유형으로 합쳤다. 본문11pt·분수선·36문제·그림·최종값·미사용 숫자7건 안내는 유지한다.
- SI→식 기초4쪽→비슷한 공식7묶음 순서다. 열량, 냉동사이클/COP/냉매, BF/현열비/혼합, 열관류, 펌프, 설비 용량, 압력/배관으로 묶었다. 기존 우선13개는 문제에 표시하며 보충문제와 관련 순서로 이어 읽는다.
- 사칙연산을 쓰는 이유는 물1 kg당 필요한 열처럼 한 가지 짧은 예제로 설명한다. 계산 단계마다 같은 설명을 되풀이하지 않는다. G 구하기뿐 아니라 각 묶음의 다른 식도 구할 글자를 남기는 법과 간단한 수치 예제를 제공한다. 상세 G 구하기는5~6쪽, 관련 공식과 문제는7쪽부터다.
- 첫 쪽 공식10개 이름은 해당 장으로 이동하는 내부 링크다. 전체7장 PDF 책갈피를 추가했다. 문제는 파란 상자, 해설은 초록 제목이며 계속되는 해설에는 원래 번호·출처를 표시한다. 참고자료 제목 링크는 마지막 쪽 안에 들어간다.
- 실제 검증: 생성기의36문제 지문·기존 최종값 보존/우선13개/유형 누락·중복0/책갈피7개 통과. 설명 예제21개 산술·되넣기, 링크10항목 목적지(줄바꿈 포함11개 영역), 기존2쪽 단위 설명 텍스트 동일(1쪽은 공식 요약 추가),34쪽 글자 경계 이탈0 확인. 최종34쪽 전체 PNG 모음과 주요 쪽 확대 확인. 실물 인쇄는 하지 않았다.
- PDF 제작기, primer, 새 practical_formula_families 모듈로 재생성한다. 기존 bundled Python/reportlab/pypdf/Pillow·Poppler를 사용했으며 설치·다운로드·원본 이미지 변환 없음. 중간35/37쪽과 링크 수를10개 영역으로 가정해 실패한 실행은 최종 결과가 아니다.
- 웹 코드·문제은행·정답·원본 그림과 웹5.3/캐시611/APK는 그대로다. 웹 빌드·기기별 UI 검사는 PDF만 바꿨으므로 재실행하지 않았다. 터미널 GitHub 인증이 없어 Push 실패 시 GitHub Desktop Push origin이 필요하다.
