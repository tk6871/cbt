[산업기사 통합 CBT 사용방법]

1. 이 폴더 안의 index.html을 실행합니다.
2. 다른 사람에게 공유할 때는 이 폴더 전체를 그대로 전달해야 합니다.
   - index.html만 보내면 문제 데이터와 이미지가 표시되지 않습니다.
   - data, assets, app.js, app.css 등의 위치와 이름을 바꾸지 마세요.
3. 학습모드에서는 화면 위쪽에서 한 화면에 표시할 문제 수를 바꿀 수 있습니다.
4. 시험모드는 PC에서 2열 문제지와 오른쪽 OMR 답안지로 표시됩니다.
   휴대폰과 태블릿에서는 1열 문제지와 슬라이드형 답안지로 자동 전환됩니다.
5. 오답, 북마크, 학습 기록은 사용하는 브라우저에 저장됩니다.
6. GitHub Pages에는 이 폴더의 내용 전체를 저장소 루트에 올리면 됩니다.
7. 인터넷 없이도 기본 기능이 작동합니다. 호스팅한 뒤에는 설치형 PWA와 오프라인 캐시도 사용할 수 있습니다.
