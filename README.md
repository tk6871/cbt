# 산업기사 통합 CBT

> 공조냉동기계·산업안전·에너지관리·설비보전산업기사 기출문제를  
> PC, 휴대폰, 태블릿에서 학습하고 실제 CBT처럼 시험 볼 수 있는 반응형 웹 애플리케이션

산업기사 통합 CBT는 여러 자격증 기출문제를 하나의 화면에서 선택하고 학습할 수 있도록 만든 개인 학습용 프로젝트입니다.  
회차별 학습, 실제 시험형 CBT, 오답노트, 계산문제 학습, 합격 분석, 공학용 계산기와 오프라인 실행을 지원합니다. 기존 CBT 화면을 기본값으로 사용하며, 산업기사와 보석관에서 심슨 테마를 선택할 수 있고 보석관에서는 선재 업고 튀어 테마도 선택할 수 있습니다.

## 🌐 바로 사용하기

### [https://tk6871.github.io/cbt/](https://tk6871.github.io/cbt/)

회원가입 없이도 브라우저에서 바로 사용할 수 있으며, 여러 기기에서 기록을 이어 볼 때만 선택적으로 동기화 계정을 만들 수 있습니다.
휴대폰에서는 브라우저의 **홈 화면에 추가** 기능을 사용하면 앱처럼 실행할 수 있습니다. iPhone·iPad는 Safari에서 처음 접속할 때 표시되는 무료 설치 안내에 따라 `공유 → 홈 화면에 추가 → 웹 앱으로 열기`를 선택하면 7일 만료 없이 사용할 수 있습니다.

### iPhone·iPad 무료 웹앱

- Apple 개발자 계정과 프로파일 서명이 필요 없는 PWA 방식입니다.
- Safari 홈 화면에 산업기사 CBT 또는 보석관 전용 아이콘으로 설치됩니다.
- 주소창 없는 전체 화면, 학습 기록 저장, 오프라인 캐시와 자동 웹 업데이트를 지원합니다.
- 설치된 웹앱으로 실행하면 홈페이지의 설치 안내는 자동으로 숨겨집니다.

### Android 앱

- Capacitor 8 기반 APK는 휴대폰 5개 하단 탭·풀이 전용 하단 도구와 태블릿 세로 메뉴·가로 2열 문제 화면을 사용합니다.
- 앱 코드와 문제 데이터는 APK에 포함하고 큰 문제·테마 이미지만 공개 사이트에서 불러와 설치 용량을 줄였습니다.
- 설치용 서명 APK는 [Android APK 최신판](https://github.com/tk6871/cbt/releases/download/android-latest/industrial-cbt-latest.apk)에서 받을 수 있습니다.
- 공개 CBT 홈페이지의 Android 전용 다운로드 팝업과 패치노트에서도 같은 최신 APK를 받을 수 있습니다. iPhone과 iPad에는 APK 안내가 표시되지 않습니다.
- Galaxy 실기기는 USB 디버깅을 허용한 뒤 `npm run android:debug`, `npm run android:install` 순서로 개발용 앱을 빌드·설치할 수 있습니다.
- 배포용 서명키는 `npm run android:key`로 최초 한 번 만들고 `npm run android:release`로 `dist/industrial-cbt-v3.5.1.apk`를 생성합니다.
- 서명키와 비밀번호는 `android/signing/`에만 보관되고 Git에서 제외됩니다. 이 폴더를 잃으면 기존 설치 앱 위에 새 버전을 업데이트할 수 없습니다.
- GitHub Actions 비밀값을 최초 한 번 등록한 뒤에는 GitHub Desktop에서 `main`을 Push origin 할 때마다 고정 다운로드 링크의 서명 APK가 자동으로 갱신됩니다.

## 🚀 주요 기능

### 1. 회차별 기출문제 학습

- 자격증과 연도를 선택해 원하는 범위만 학습
- 학습모드와 시험모드를 회차 카드에서 바로 실행
- 정답 후 자동으로 열린 해설 닫기·다시 보기와 문제마다 정답에 연결된 `쉽게 외우기` 카드
- 한 화면에 표시할 문제 수 선택
- 마지막으로 풀던 답안과 진도를 저장하고 이어서 학습
- 학습 내역 메뉴에서 날짜·점수·풀이 수·오답 수를 확인하고 이어하기·같은 문제 다시 풀기
- 선택한 연도 범위에서 과목별로 고르게 뽑은 랜덤 60문제 학습
- 창을 닫거나 기기를 다시 켜도 미완료 학습의 답안·페이지·킵 상태를 자동 복원
- 연도·회차 학습은 현재 풀이 순서대로 1번부터 표시하고 원문 번호는 참고용으로 함께 표시
- 과목 변경 지점을 눈에 띄게 구분

### 2. 실제 시험형 CBT

- 과목별 균형 출제와 60문제 모의시험
- 실제 시험처럼 문제 영역과 OMR 답안지 분리
- 선택한 답 재클릭 취소와 문제 화면·OMR 상태 동기화
- 남은 시간, 답안 현황, 시험 중 킵과 채점 결과 제공
- 회차별 점수·마지막 풀이 회차와 과목별 점수·과락 여부 확인
- Q-Net 필기 기준에 따른 산업기사 과락·평균 판정과 기능사·기능장 총점 판정
- PC에서는 2문제씩 배치하고 작은 화면에서는 자동으로 1열 전환

### 3. 맞춤형 복습

- 틀린 문제를 자동으로 오답노트에 저장
- 연도·회차별 오답과 내 답·정답을 보존하고 해당 회차 오답만 다시 풀기
- 북마크, 검색, 최근 학습 기록 지원
- 문제 검색에서 별표를 누른 즐겨찾기 문제만 따로 모아 보기
- 연도 범위별 랜덤 출제
- 정답률이 낮은 문제와 반복 출제 유형 학습
- 망각곡선 기반 복습 대기열과 취약 과목 분석

### 4. 합격 엔진과 학습 통계

- 문제별 정오답과 반복 횟수를 이용한 숙련도 분석
- 과목별 예상 점수와 과락 위험 표시
- 최근 모의시험 점수 흐름 확인
- 선택 범위 학습률과 예상 합격 가능성 제공

> 합격 가능성과 예상 점수는 학습 기록을 이용한 참고용 지표이며 실제 시험 결과를 보장하지 않습니다.

### 5. 원문 이미지형 복원문제

- 이미지 비율을 유지한 문제 표시
- 공조 복원문제는 설정에서 원문 이미지 속 ①·②·③·④를 바로 눌러 답하는 방식 선택 가능
- 답안 방식은 풀이 화면의 설정에서 바꾸며, 상단에는 별도 안내 바를 표시하지 않음
- 이미지 답안 선택 표시는 체크 마커(기본)·영역 색상 박스 중 선택하며, 마우스 올림·클릭·선택이 같은 좌표를 사용하고 두 줄·세 줄 보기도 번호부터 마지막 줄까지 한 박스로 표시
- 2021~2026년 공조 복원문제 1,020장을 전수 검수하고, 실제 선택지가 보이는 1,019장에서 이미지 직접 선택 지원
- 수식·분수·회로·그림 보기는 PaddleOCR과 원본 픽셀 범위를 함께 사용해 일부 글자만 강조되는 문제 보완
- 저장된 화면 설정이 없는 첫 방문은 다크 모드로 시작하며, 복원문제 이미지는 눈부심 완화 남색을 기본으로 사용하거나 항상 원본으로 표시 가능
- 긴 마지막 답안은 PaddleOCR 상자를 실제 어두운 글자 픽셀까지 확장해 두 줄·세 줄의 마지막 획까지 강조
- 분모·마지막 보기가 잘렸던 공조 복원문제 원문 15장은 배포 PDF와 동일 문제 원본을 대조해 기존 Real-ESRGAN 방식으로 다시 복원
- 수정 배포 PDF를 반영해 2026년 2회 14번 정답과 중복됐던 2022년 3회 6번 원문·정답·해설 교정
- 크게 보기와 답안 안내는 이미지 아래에 따로 표시해 문제·선택지를 가리지 않음
- PC와 모바일에 맞춘 답안 버튼 크기
- **크게 보기** 버튼을 통한 원문 확대
- 확대 화면에서 이미지 또는 배경을 눌러 바로 닫기
- 원문 이미지와 문제 번호를 함께 표시해 검증 가능
- 한솔아카데미 공조 2017~2025년 1,920문항을 별도 원문 문제관으로 제공
- 한솔 1,920문항도 원문 이미지의 ①~④ 보기를 직접 누르는 단일 답안 박스 지원
- 1,296문항은 문제·보기·정답 보기가 모두 일치하는 COMCBT 해설을 다시 연결하고, 나머지 624문항도 단순 정답 암기가 아닌 문제별 원리·공식·계산 순서로 설명
- 동일 문제·보기 대조로 정답표 오연결 54문항을 교정하고, 공조 복원문제 32문항에는 기존 해설 아래에 COMCBT 동일 문제 추가 해설을 함께 표시
- 2020년 스캔 160장은 Real-ESRGAN 4배 처리 후 2배 축소 방식으로 화질 개선
- 다크 모드에서는 복원문제뿐 아니라 일반 문제·선택지·한솔 원문 이미지도 밝기를 낮춰 표시

### 6. 학교 중간·기말고사 준비

- 자격증 문제와 분리된 `학교 시험 준비` 메뉴에서 과목·학기·중간·기말·쪽지시험 범위를 작성
- 객관식 문제 4개 보기, 정답, 해설, 교재 페이지와 선생님 강조사항 입력
- 입력한 객관식 시험지를 기존 학습모드와 CBT모드로 실행
- 주관식 암기카드의 답을 가렸다가 펼쳐 보고 `외웠어요`·`다시 보기`로 확인 횟수 기록
- 교재 범위와 예상 출제 내용을 시험지 카드에서 함께 확인
- 브라우저에 별도 저장하며 JSON 백업·불러오기로 기기 이동과 자료 보관 지원

### 7. 편의 기능

- 새 배치와 화면 전환을 한 번에 켜고 끄는 동적 UI 옵션(기본값 ON)
- 문제풀이 화면은 `기본 CBT`(기존 v2.7 화면·기본값)·`COMCBT 모드`·`컴뱃 CBT` 중 설정에서 선택
- COMCBT 모드는 데스크톱에서 한 화면 6문제·독립 2열·고정 하단 이동 바를 사용해 스크롤을 줄이고, 컴뱃 CBT는 한 화면 4문제·진행 HUD를 사용
- COMCBT 고정 하단 바에서 학습 결과 보기 또는 시험 제출·채점을 바로 실행
- COMCBT에서 전체·미응답·킵·현재 과목 OMR 필터와 `다음 미응답` 이동 지원
- 시험모드 OMR은 PC·모바일 모두 닫힌 상태로 시작하고 사용자가 `OMR 열기`를 눌렀을 때만 표시
- 기본 CBT·COMCBT·컴뱃 CBT 상단에 진행률·완료·미응답·킵 현황을 계속 표시
- COMCBT에서만 `1`~`4` 답 선택, 방향키 이동, `K` 킵, `B` 북마크, `E` 해설 패널 단축키 지원
- 학습모드에서 정답을 맞히면 모든 화면의 해설이 즉시 표시되며, COMCBT 해설은 PC 오른쪽 패널·모바일 아래쪽 시트로 자동 표시
- 설정 화면에서만 기본 CBT·심슨 테마 UI 선택과 학습관별 저장
- 보석관에서만 선재 업고 튀어 테마와 사진 자동 교체 시간(끔·5초·10초·30초·1분·3분·5분) 설정
- 라이트·다크·기기 설정 테마
- 같은 주소에서 기기를 자동 인식하는 경량 화면과 설정의 자동·모바일·PC 화면 선택
- 처음부터 전체 문제 데이터를 읽지 않고 현재 선택한 종목만 불러오는 초기 로딩 최적화
- 나눔고딕 Regular·Bold와 D2Coding Regular·Bold 글꼴 선택
- 문제 풀이 중 글자 크기 즉시 조절
- 학습·CBT 풀이 중 설정창에서 테마·글씨·답안 배치·OMR을 변경하고 현재 답안 유지
- 기존 CBT는 데스크톱 문제를 서로 높이에 영향을 주지 않는 두 개의 독립 열로 배치하고, 짧은 글 보기와 4개 이미지 보기는 2×2로 압축해 스크롤 감소
- 복원 이미지 문제의 `이미지 직접 선택`, `번호 + 답안 문구`, 기존 큰 번호 답안 배치 선택(기본값은 기존 방식)
- 현재 문제에 맞춘 OMR 자동 이동과 문제 이미지 잘림 방지
- 별도 팝업 공학용 계산기
- 문제별 초보자용 AI 질문 프롬프트 복사
- 학습 기록 JSON 내보내기·불러오기
- 신버전 자동 확인과 캐시 갱신
- 구버전 CBT 화면과 별도 보석 학습관 제공

### 8. 선택형 심슨 테마

- 기본 CBT·심슨 테마를 설정에서만 전환
- 산업기사·보석관·이전 버전·공학용 계산기가 같은 선택값 공유
- 스프링필드풍 하늘색 배경, 노란색 메뉴, 굵은 외곽선과 말풍선 알림 적용
- 심슨 테마에서도 라이트·다크·기기 설정 모드 지원
- 동적 UI를 켜면 메뉴·카드·학습 화면이 움직이며 재배치되고, 끄면 v2.4.2 방식의 기존 배치로 복원
- 상단 메뉴를 단순하게 유지하고 UI 스타일 변경은 화면·데이터 설정에 모아 제공
- 호머·바트 목 조르기 장면과 `King-Size Homer` 본편의 여러 장면을 사진 중심 전용 대시보드에 사용
- 왼쪽 메뉴 전체에 킹 사이즈 호머를 표시하고 데스크톱·모바일 메뉴마다 서로 다른 본편 사진 아이콘 적용
- 손가락을 맞댄 번즈의 여러 장면을 접속할 때 무작위로 표시
- 시험·학습 결과의 심슨 장면을 크게 표시하고 좁은 화면에서는 가로 배너로 배치

### 9. 계산문제와 공조 시험 암기장

- 계산이 필요한 문제를 전체·과목·회차별로 선택
- 정답 후 무엇을 구하는지, 공식, 기호, 사용 이유, 숫자 대입과 단위를 6단계로 안내
- 공조냉동 기출 학습에 자주 쓰는 냉동능력·열량·습공기·배관·송풍기·전기 공식을 시험 직전 암기장으로 제공
- SI 단위 변환, 압력, 물·공기·얼음의 비열과 잠열을 덧셈·곱셈부터 따라갈 수 있는 순서로 안내

### 10. 보석관 전용 테마와 정식 문제풀이 설정

- 선재 업고 튀어 테마는 보석관에서만 제공하며 산업기사 설정에는 표시하지 않음
- 류선재 단독 장면 6장과 변우석 일상·SNS 사진 4장을 보석관 홈·로고·메뉴에서 자동 순환
- 새 기기의 사진 교체 기본값은 3분이며 끄기·초·분 단위로 조절 가능
- 문제 이미지 비율 보호와 OMR 현재 문제 자동 이동을 정식 기본 기능으로 제공
- 복원 이미지 문제는 번호 옆 답안 문구 방식과 기존 큰 번호 방식 중 선택
- 보석관 페이지에서 설치한 PWA는 공용 홈이 아닌 보석관으로 바로 시작

### 11. 신기술 학습관

- 최신 정식 기능을 패치노트와 분리해 직접 눌러보는 안내 화면 제공
- 풀이 중 설정, 답안 배치 전환과 OMR 자동 이동 체험
- 원본과 업스케일링 결과를 문제 풀이와 같은 확대 화면으로 비교
- 복원문제 다크 이미지 표시를 설정에서 고르고 실제 학습 화면에서 체험

## 💾 학습 기록

학습 기록은 기본적으로 현재 브라우저의 `localStorage`와 `IndexedDB`에 저장됩니다.

- 기록 내보내기: 설정 → 화면과 학습 데이터 → **기록 내보내기**
- 기록 불러오기: 설정 → 화면과 학습 데이터 → **기록 불러오기**
- 기록 초기화: 설정 → 화면과 학습 데이터 → **전체 초기화**

브라우저 데이터나 앱을 삭제하면 기록이 사라질 수 있으므로, 기기를 바꾸거나 중요한 기록을 보관할 때는 먼저 백업 파일을 내려받는 것을 권장합니다.

## 🧮 공학용 계산기

문제 풀이 화면에서 계산기 버튼을 누르면 별도 창으로 실행됩니다.

- 사칙연산과 괄호
- 삼각함수와 역삼각함수
- 로그·자연로그·지수
- 제곱·제곱근·거듭제곱
- 공학 표기와 계산 기록
- 산업기사에서는 기본 CBT·심슨, 보석관에서는 기본 CBT·심슨·선재 업고 튀어 계산기 스킨 전환
- 동적 UI가 켜져 있을 때 계산기 스킨 이동 전환

계산 엔진은 로컬에 포함된 Math.js를 사용하므로 오프라인에서도 동작합니다.

## 🚢 GitHub Pages 배포

1. 저장소에 변경 사항을 Commit하고 GitHub로 Push합니다.
2. GitHub 저장소의 **Settings → Pages**로 이동합니다.
3. Source를 **Deploy from a branch**로 선택합니다.
4. Branch는 `main`, 폴더는 `/(root)`로 설정합니다.
5. 저장 후 Pages 주소가 만들어질 때까지 기다립니다.
