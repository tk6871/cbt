# CBT 학습 프로젝트

개인 학습용 웹 앱입니다. PC·휴대폰·태블릿에서 문제를 풀고 학습 기록을 관리합니다.

[웹 앱 열기](https://tk6871.github.io/cbt/)

## 주요 기능

- 학습·모의시험, 문제 검색과 자료별 연습
- 오답·즐겨찾기·이어풀기와 선택형 계정 동기화
- 이미지 확대, 화면 설정, 다크·라이트 모드
- 전 과목 문제·보기·해설의 해상도 유지 WebP90 표시
- 웹앱 설치 및 Android 앱 지원

개별 자료의 내용·출처·검토 이력은 이 공개 소개 문서에 나열하지 않습니다. 자료의 권리와 필요한 출처 표시는 해당 자료에 보존합니다.

## 로컬 개발

Node.js와 npm이 필요합니다.

```bash
npm install
npm run dev
```

변경 후에는 관련 검사를 실행합니다.

```bash
npm run typecheck
npm run build
npm run test:pwa
npm run test:search-policy
```

빌드 결과는 `modern/`에 생성됩니다. 웹 배포에는 루트 HTML·데이터·이미지·서비스워커도 필요합니다. 문제 ID와 저장 형식의 호환성을 유지하고, 인증 정보·개인 자료 원본은 공개 저장소에 넣지 않습니다.

## 공개 범위와 검색

웹 화면은 검색 제외를 요청합니다. 이 설정은 접근 제한이 아니며 공개 GitHub 저장소·과거 커밋·직접 연결된 파일을 비공개로 만들지 않습니다. 이미 검색된 내용은 즉시 삭제되지 않을 수 있습니다.

## 자료·권리 안내

공식 시험 서비스가 아니며 문제·해설에 오류가 있을 수 있습니다. 제3자 자료의 권리는 각 권리자에게 있습니다. 소스의 공개 열람은 자료의 복제·재배포·상업적 이용 허가를 뜻하지 않습니다.
