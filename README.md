# CBT 학습 프로젝트

Vue 3·TypeScript 기반 개인 학습용 웹 앱입니다. PC·휴대폰·태블릿에서 문제를 풀고 학습 기록을 관리합니다.

이 README는 공개 사용·개발 안내만 담습니다. 개인 시험 범위, 제공 자료의 세부 내용, 작업 중 메모와 누적 버전별 설명은 싣지 않습니다.

## 사용하기

[웹 앱 열기](https://tk6871.github.io/cbt/)

- 학습모드·CBT 시험모드, 회차·주제별 선택과 랜덤 연습
- 설비보전기사 별도 기출 종목, 등록 해설·그림 보기·원본 보존 화질 개선과 다크·라이트 표시
- 필답형 복원 비율 실전: 유형별 구성에 맞춘12문제·90분, 제출 전 문제별 풀이 확인·확인 표시 저장, 제출 후 자가채점
- 필답형 계산·공식 공부: 기호·SI 단위·계산 순서·단위 약분·반올림 설명, 그림 포함 학습 PDF
- 계산 시험 대비는 CGT·CR·COP·BF 중심13문항 우선 선택, 전체36문항 전환 지원
- 문제별 필요한 계산·안 쓰는 숫자·조건 구별, 한 줄 공식10개 바로가기를 포함한29쪽 계산 학습 PDF
- 계산 공부 첫 부분에서 공식 이름·언제 쓰는지·기호 뜻·짧은 암기법 확인
- 필답형은 문제 아래 풀이를 확인하고 최대12개 표시·이어보기 선택을 저장
- 필답형 전용 풀이 화면과 그림 전체 맞춤·400% 그림 확대, 모바일 메뉴 안정화
- 필답형 그림 확대는 고정된 창 안에서만 배율 변경·스크롤, 그림 재클릭으로 닫기
- 풀이 뒤로가기 후에도 닫힌 모바일 메뉴가 화면·터치를 가리지 않도록 처리
- 학교 연습 모음의 분리 선택과 주제별 계산 문제 포함/제외
- 학교 연습의 최신 회차 대표 문제·출제 회차 표시와 계산 분류 확인
- 검토 승인된 반복의 통합 이유·원문 차이·보존 문항을 별도 대장에서 확인
- 학교 연습 모음별 자료 출처 구분과 기존 이어풀기 기록 보존
- 교재 본문과 연결 확인된 문제만 선택, 기존 전체 목록 전환과 미확인 대조 목록 제공
- 풀기 전 기존 문제 목록·교재 원문 선택, 원문 해설 이미지와 화질 개선·다크/라이트 표시
- 목차별 연습과 계산 개수 선택, 출제 구성을 바꾸지 않는 별도 분류 검토 화면
- 학교 연습의 유사 주제 연속 배치와 기존 순서 선택, 랜덤 선택 후 주제별 배치 옵션
- 오답·즐겨찾기·미완료 풀이 기록과 이어풀기
- 문제 검색, 계산기, 선택형 화면 설정과 다크·라이트 모드
- 검색·오답·계산 목록 원문 미리보기, 계산 목록 페이지 탐색과 필답 공식·문제 바로가기
- 필답 공식·숫자 대입 분수 표시, 분자·분모 읽기와 같은 수식의 학습 PDF
- 학습 PDF의 사칙연산·이항·구할 글자 남기기 기초, 비슷한 공식7묶음·문제 상자/해설 구분
- [시험 직전 한글 공식 한 장](output/pdf/hvac-practical-formula-quick-sheet.pdf): CGT·CR·COP·BF와 보충 공식, 분수·단위 요약
- 원문 이미지 문제의 확대 보기와 다크·라이트·원본 표시 설정
- 큰 PC 화면의 읽기 폭 제한, 문제 원본 표시·확대와 테마 아이콘 최적화
- 시험 자료실 필요 시 로딩, 연결 실패 재시도와 진행 중 풀이 복원
- 지원 원문 이미지의 답안 직접 선택과 체크 마커·영역 강조 선택
- 필답형 복합 답안·이해용 설명과 문제별 이상 신고, 원본 대조 그림 보수
- 학습 기록은 기본적으로 현재 브라우저에 저장되며 계정 동기화는 선택 사항

iPhone·iPad는 Safari의 `공유 → 홈 화면에 추가`로 설치합니다. Android는 웹앱 또는 [서명 APK](https://github.com/tk6871/cbt/releases/download/android-latest/industrial-cbt-latest.apk)를 이용할 수 있습니다. APK의 온라인 화면은 웹 배포를 따라 갱신되며, 네이티브 기능 변경에는 앱 업데이트가 필요합니다. 오프라인 화면은 설치된 APK의 내장 버전입니다.

## 로컬 개발

Node.js와 npm이 필요합니다.

```bash
npm install
npm run dev
```

터미널에 표시되는 로컬 주소를 엽니다.

```bash
npm run typecheck
npm run build
npm run test:pwa
```

빌드 결과는 `modern/`에 생성됩니다. 배포 시 루트 HTML·데이터·이미지·서비스워커도 함께 반영해야 합니다.

## 구조

```text
src/       화면·학습 로직
data/      문제·회차 데이터
assets/    이미지·글꼴·아이콘
tools/     검증·변환·빌드 도구
modern/    웹 배포 생성물
android/   Android 앱 프로젝트
```

기술 구성은 Vue 3, TypeScript, Vite, PWA, IndexedDB이며 계정 동기화는 선택형 Supabase 기능입니다.
