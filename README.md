# CBT 학습 프로젝트

Vue 3·TypeScript 기반 개인 학습용 웹 앱입니다. PC·휴대폰·태블릿에서 문제를 풀고 학습 기록을 관리합니다.

이 README는 공개 사용·개발 안내만 담습니다. 개인 시험 범위, 제공 자료의 세부 내용, 작업 중 메모와 누적 버전별 설명은 싣지 않습니다.

## 사용하기

[웹 앱 열기](https://tk6871.github.io/cbt/)

- 학습모드·CBT 시험모드, 회차·주제별 선택과 랜덤 연습
- 오답·즐겨찾기·미완료 풀이 기록과 이어풀기
- 문제 검색, 계산기, 선택형 화면 설정과 다크·라이트 모드
- 학습 기록은 기본적으로 현재 브라우저에 저장되며 계정 동기화는 선택 사항

iPhone·iPad는 Safari의 `공유 → 홈 화면에 추가`로 설치합니다. Android는 웹앱 또는 [서명 APK](https://github.com/tk6871/cbt/releases/download/android-latest/industrial-cbt-latest.apk)를 이용할 수 있습니다. APK의 온라인 화면은 웹 배포를 따라 갱신되며, 네이티브 기능 변경에는 앱 업데이트가 필요합니다. 오프라인 화면은 설치된 APK의 내장 버전입니다.

## 로컬 개발

Node.js와 npm이 필요합니다.

```bash
npm install
npm run dev
```

터미널에 표시되는 로컬 주소를 엽니다.

```bash
npm run typecheck
npm run build
npm run test:pwa
```

빌드 결과는 `modern/`에 생성됩니다. 배포 시 루트 HTML·데이터·이미지·서비스워커도 함께 반영해야 합니다.

## 구조

```text
src/       화면·학습 로직
data/      문제·회차 데이터
assets/    이미지·글꼴·아이콘
tools/     검증·변환·빌드 도구
modern/    웹 배포 생성물
android/   Android 앱 프로젝트
```

기술 구성은 Vue 3, TypeScript, Vite, PWA, IndexedDB이며 계정 동기화는 선택형 Supabase 기능입니다.

## 업데이트·기록 보호

- 데이터 변경 시 기존 문항 ID와 저장 형식의 호환성을 확인합니다.
- 화면·기능 변경 후 타입 검사, 빌드와 관련 회귀 검사를 실행합니다.
- 웹 배포 버전·캐시와 앱 내 패치노트를 함께 갱신합니다.
- 브라우저 저장 데이터를 삭제하기 전 학습 기록을 내보내어 보관하세요.
- 인증 토큰, 비밀키, 서명키와 개인 자료 원본은 공개 저장소에 넣지 않습니다.
