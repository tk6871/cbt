# 산업기사 통합 CBT

> 공조냉동기계·산업안전·에너지관리·설비보전산업기사 기출문제를  
> PC, 휴대폰, 태블릿에서 학습하고 실제 CBT처럼 시험 볼 수 있는 반응형 웹 애플리케이션

산업기사 통합 CBT는 여러 자격증 기출문제를 하나의 화면에서 선택하고 학습할 수 있도록 만든 개인 학습용 프로젝트입니다.  
회차별 학습, 실제 시험형 CBT, 오답노트, 합격 분석, 공학용 계산기와 오프라인 실행을 지원합니다.

## 🌐 바로 사용하기

### [https://tk6871.github.io/cbt/](https://tk6871.github.io/cbt/)

별도의 회원가입이나 프로그램 설치 없이 브라우저에서 바로 사용할 수 있습니다.  
휴대폰에서는 브라우저의 **홈 화면에 추가** 기능을 사용하면 앱처럼 실행할 수 있습니다.

## 🚀 주요 기능

### 1. 회차별 기출문제 학습

- 자격증과 연도를 선택해 원하는 범위만 학습
- 학습모드와 시험모드를 회차 카드에서 바로 실행
- 한 화면에 표시할 문제 수 선택
- 마지막으로 풀던 답안과 진도를 저장하고 이어서 학습
- 과목 변경 지점을 눈에 띄게 구분

### 2. 실제 시험형 CBT

- 과목별 균형 출제와 60문제 모의시험
- 실제 시험처럼 문제 영역과 OMR 답안지 분리
- 남은 시간, 답안 현황, 보류 문제와 채점 결과 제공
- 과목별 점수, 평균 점수와 과락 여부 확인
- PC에서는 2문제씩 배치하고 작은 화면에서는 자동으로 1열 전환

### 3. 맞춤형 복습

- 틀린 문제를 자동으로 오답노트에 저장
- 북마크, 검색, 최근 학습 기록 지원
- 연도 범위별 랜덤 출제
- 정답률이 낮은 문제와 반복 출제 유형 학습
- 망각곡선 기반 복습 대기열과 취약 과목 분석

### 4. 합격 엔진과 학습 통계

- 문제별 정오답과 반복 횟수를 이용한 숙련도 분석
- 과목별 예상 점수와 과락 위험 표시
- 최근 모의시험 점수 흐름 확인
- 선택 범위 학습률과 예상 합격 가능성 제공

> 합격 가능성과 예상 점수는 학습 기록을 이용한 참고용 지표이며 실제 시험 결과를 보장하지 않습니다.

### 5. 원문 이미지형 복원문제

- 이미지 비율을 유지한 문제 표시
- PC와 모바일에 맞춘 답안 버튼 크기
- **크게 보기** 버튼을 통한 원문 확대
- 확대 화면에서 이미지 또는 배경을 눌러 바로 닫기
- 원문 이미지와 문제 번호를 함께 표시해 검증 가능

### 6. 편의 기능

- 라이트·다크·기기 설정 테마
- 문제 풀이 중 글자 크기 즉시 조절
- 별도 팝업 공학용 계산기
- 문제별 초보자용 AI 질문 프롬프트 복사
- 학습 기록 JSON 내보내기·불러오기
- 신버전 자동 확인과 캐시 갱신
- 구버전 CBT 화면과 별도 보석 학습관 제공

## 💾 학습 기록

학습 기록은 기본적으로 현재 브라우저의 `localStorage`와 `IndexedDB`에 저장됩니다.

- 기록 내보내기: 설정 → 화면과 학습 데이터 → **기록 내보내기**
- 기록 불러오기: 설정 → 화면과 학습 데이터 → **기록 불러오기**
- 기록 초기화: 설정 → 화면과 학습 데이터 → **전체 초기화**

브라우저 데이터나 앱을 삭제하면 기록이 사라질 수 있으므로, 기기를 바꾸거나 중요한 기록을 보관할 때는 먼저 백업 파일을 내려받는 것을 권장합니다.

## 🧮 공학용 계산기

문제 풀이 화면에서 계산기 버튼을 누르면 별도 창으로 실행됩니다.

- 사칙연산과 괄호
- 삼각함수와 역삼각함수
- 로그·자연로그·지수
- 제곱·제곱근·거듭제곱
- 공학 표기와 계산 기록

계산 엔진은 로컬에 포함된 Math.js를 사용하므로 오프라인에서도 동작합니다.

## 📂 프로젝트 구조

```text
.
├─ index.html              # 산업기사 통합 CBT
├─ jewelry.html            # 보석·귀금속 별도 학습관
├─ legacy.html             # 구버전 CBT 화면
├─ calculator.html         # 공학용 계산기
├─ admin.html              # 선택형 관리자 화면
├─ src/
│  ├─ cbt/                 # Vue CBT 화면과 학습 로직
│  ├─ admin/               # 관리자 화면
│  └─ visitor.ts           # 선택형 접속 기록 모듈
├─ data/                   # 종목별 문제·회차·패치노트 데이터
├─ assets/                 # 문제 이미지와 앱 아이콘
├─ modern/                 # Vite 배포 빌드 결과
├─ supabase/               # 선택형 데이터베이스와 Edge Function
├─ app.js / app.css        # 구버전 CBT
└─ sw.js                   # 오프라인 캐시와 업데이트
```

## ▶️ 로컬에서 실행하기

Node.js와 pnpm이 설치되어 있어야 합니다.

```bash
pnpm install
pnpm dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 열면 됩니다.

### 검사 및 배포 파일 생성

```bash
pnpm typecheck
pnpm build
```

빌드 결과는 `modern/` 폴더에 생성되며, 루트의 HTML·데이터·이미지 파일과 함께 배포합니다.

## 🚢 GitHub Pages 배포

1. 저장소에 변경 사항을 Commit하고 GitHub로 Push합니다.
2. GitHub 저장소의 **Settings → Pages**로 이동합니다.
3. Source를 **Deploy from a branch**로 선택합니다.
4. Branch는 `main`, 폴더는 `/(root)`로 설정합니다.
5. 저장 후 Pages 주소가 만들어질 때까지 기다립니다.

이 저장소의 공개 주소는 다음과 같습니다.

```text
https://tk6871.github.io/cbt/
```

## 🔄 업데이트 방법

문제, 해설 또는 기능을 수정한 뒤에는 다음 항목을 함께 갱신합니다.

1. `data/changelog-vue.js`와 `CHANGELOG.md`
2. HTML과 서비스워커의 정적 파일 버전
3. `sw.js`의 캐시 이름
4. `pnpm typecheck`
5. `pnpm build`

사이트에서는 새 버전을 확인한 뒤 **신버전 적용** 버튼으로 최신 캐시를 불러옵니다.

## 🔒 데이터 및 보안

- 학습 기록은 기본적으로 사용자의 브라우저에 저장됩니다.

- Supabase를 연결할 경우 서버 전용 비밀키는 브라우저 코드나 GitHub 저장소에 올리지 않아야 합니다.
- `service_role` 키, 데이터베이스 비밀번호와 개인 인증 정보는 공개 파일에 포함하지 마세요.

## ⚠️ 문제 자료 안내

이 프로젝트는 자격증 시험 학습과 개인적인 검증을 목적으로 제작되었습니다.

- 문제·이미지·해설의 권리는 각 출처와 원저작권자에게 있습니다.
- 복원문제는 실제 시험 문항과 표현·보기·정답이 다를 수 있습니다.
- 정답과 해설에 오류가 있을 수 있으므로 공식 기준과 원문 자료를 함께 확인해 주세요.
- 자료를 다른 목적으로 재배포할 때는 해당 자료의 이용 조건과 허가 범위를 먼저 확인해 주세요.

- 이 프로젝트는 **한국산업인력공단, Q-Net 또는 COMCBT의 공식 서비스가 아닙니다.**
- 출처 표기 누락이나 권리 관련 요청이 있으면 저장소의 Issue를 통해 알려주세요.
