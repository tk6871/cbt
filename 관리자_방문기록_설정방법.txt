[CBT 관리자 방문·학습 기록 설정]

현재 관리자 화면과 기록 코드는 완성되어 있지만, 실제 기록 저장을 위해 Supabase 프로젝트 연결이 필요합니다.
GitHub Pages 자체에는 데이터베이스와 서버 기능이 없기 때문입니다.

1. https://supabase.com 에서 새 프로젝트를 만듭니다.

2. Supabase의 SQL Editor에서 이 폴더의 supabase/schema.sql 내용을 실행합니다.

3. Authentication > Users에서 관리자 로그인 계정 1개를 만듭니다.

4. SQL Editor에서 아래 문장을 실제 관리자 이메일로 바꿔 실행합니다.
   insert into public.admin_users(email) values ('내이메일@example.com')
   on conflict (email) do nothing;

5. Supabase CLI로 Edge Function을 배포합니다.
   supabase functions deploy cbt-analytics

6. Edge Function의 ALLOWED_ORIGIN 비밀값을 실제 홈페이지 주소로 설정합니다.
   예: https://tk6871.github.io
   SUPABASE_URL과 SUPABASE_SERVICE_ROLE_KEY는 Supabase 배포 환경에서 제공됩니다.
   SERVICE_ROLE_KEY는 절대로 cloud-config.js나 GitHub에 올리지 마세요.

7. cloud-config.js를 열어 다음 값을 입력합니다.
   enabled: true
   supabaseUrl: 프로젝트 URL
   supabaseAnonKey: 프로젝트의 public anon key

8. 사이트 파일을 GitHub에 올린 뒤 다음 주소로 관리자 화면에 접속합니다.
   https://tk6871.github.io/cbt/admin.html

[보안 구조]
- 일반 방문자는 기록을 전송만 하며 데이터 조회 권한이 없습니다.
- 관리자 계정으로 로그인하고 admin_users에 등록된 이메일만 조회할 수 있습니다.
- IP 주소는 브라우저가 아니라 Edge Function에서 확인합니다.
- 방문 IP, 최근 접속, 푼 문제, 정오답, 시험 점수는 관리자 화면에서만 표시됩니다.
- service role key는 Edge Function 서버에만 보관합니다.

[참고]
- 같은 와이파이를 쓰는 여러 사람은 같은 공인 IP로 보일 수 있습니다.
- 휴대폰 통신망이나 VPN을 사용하면 IP가 자주 바뀔 수 있습니다.
- IP만으로 사람의 실제 이름을 확인할 수는 없습니다.
